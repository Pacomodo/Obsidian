**DEF**) A group <$G$,$*$> is a set $G$, closed under a binary operation $*$, such that the following axioms are satiesfied.

* For all $a, b, c \in G$, $(a * b) * c = a * (b * c)$ (**associativity of $*$**)
* There is an element $e \in G$ such that $\forall x \in G$, $e * x = x * e = x$ (**identity element $e$ for $*$**)
* For each $a \in G$, there is an element $a' \in G$ such that $a * a' = a' * a = e$ (**inverse $a'$ of $a$)
