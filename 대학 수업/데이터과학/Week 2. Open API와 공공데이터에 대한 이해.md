### 공공데이터의 뜻과 관리 지침

#### 공공데이터의 뜻과 공공데이터법

* 공공데이터의 정의
**공공 기관**이 법령 등에서 정하는 목적을 위하여 **생성 또는 취득하여 관리**하고 있는 데이터.
공공기관장은 **기계 판독이 가능한 형태**로 공공데이터를 정비해야 됨.
즉, Machine readable해야한다.

#### 기계 판독과 Open Data 5 Star

* 오픈 데이터를 별을 이용하여 5개의 단계로 구분
* Tim Berners-Lee가 주장함(WWW의 창시자)

1. 특정 SW에서 **읽기**만 가능.
2. 특정 SW에서 **읽기, 수정, 변환** 가능
3. 적어도 하나의 **비독점적** SW에서 읽기, 수정, 변환 가능
4. URI에 기초하여, 데이터의 속성 및 관계에 대해 기술
5. 웹 상의 다른 데이터와 연결되어 제공되는 데이터

#### Open Data 5 Star의 사례와 의미

1. PDF(미충족 포맷)
2. HWP, XLS, JPG, PNG, MP3, WMV, MPEG, SWF(최소충족포맷)
3. CSV, JSON, XML(3스타부터 오픈 포맷)
4. RDF
5. LOD

* **미충족 포맷**의 경우 공공데이터포털에 등록이 불가능함
* 공공기관은 소관 공공데이터를 **오픈 포맷**의 형태로 제공하는 것이 원칙.

3스타부터는 기계 판독이 가능한 형태이다.
RDF는 언어 규약의 하나. LOD는 특정한 확장자가 아님. Linked open data. 데이터 상의 연결에 기초한 데이터.

#### 공공데이터가 우리 곁에 오기까지

1. 생성수집 - 기관이 생성하는 데이터를 기계 판독이 가능한 꼴로 정비. 데이터 개을 위해 공공 데이터의 제공대상을 정의.(어떤 데이터를 누구에게 제공할 것인지)
2. 처리 - 제공하고자 하는 데이터가 법적으로 공공데이터에 해당하는지 검토. 제공제외대상이 포함되어 있는지, 저작권을 확보했는지 등을 확인
3. 등록 - 공공데이터목록등록관리시스템에 제공대상 목록 및 데이터를 등록.
4. 제공 - 기관의 데이터를 국민과 기업등을 대상으로 개방 및 제공.
5. 사후관리 - 제공 이후의 공공데이터의 변경사항, 갱신주기등을 반영. 불편 사항 접수 및 분쟁 조정 처리

#### 공공데이터 제공 신청과 그 절차

* 공공데이터 목록에 나타나지 않는 데이터라고 할 지라도 신청 가능.
* 공공기관장은 저작권 등의 요소를 검토 후 10일 이내에 제공여부를 결정해야 함.
