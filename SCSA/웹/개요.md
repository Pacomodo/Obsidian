웹(WorldWideWeb)
- 표준 기관 : W3C
- 기본 언어 : HTML
- 프로토콜 : HTTP

HTML(HyperTextMarkupLanguage)
- 마크업 언어란? 태그로 구성된 언어. `<table>, <a>`
- 마크업 언어 종류 : HTML, XML
- HTML, XML은 모두 SGML의 파생언어이다.
- SGML : 문서를 표현하고 구조화하는 역할을 담당
	- HTML : 문서를 표현
	- XML : 문서를 구조화하는 역할
	```xml
	<지역들>
		<지역 시도 = "서울" 군구="중구" 온도="10" 습도="20"/>
		<지역 시도 = "서울" 군구="중구" 온도="10" 습도="20"/>
		...
	</지역들>
	```

웹브라우저
![[Pasted image 20251027092713.png]]
HTML문서는 웹브라우저 내부에서 실행된다.
[렌더링 엔진](https://ko.wikipedia.org/wiki/%EB%B8%8C%EB%9D%BC%EC%9A%B0%EC%A0%80_%EC%97%94%EC%A7%84)을 통해 한 줄 한 줄 실행되어 보여준다.
브라우저 엔진의 주된 역할은 HTML 문서와 기타 자원의 웹 페이지를 사용자의 장치에 상호작용적인 시각 표현으로 변환시키는 것이다.
![[Pasted image 20251027093345.png]]
엔진이 다양함 $\rightarrow$ 렌더링 다양 $\rightarrow$ 웹표준을 지키려고 노력해야한다.

웹표준은 W3C에서 제공한다.
웹브라우저의 구성요소에는 자바스크립트 해석기가 따로 있음.
HTML, CSS는 브라우저 엔진과 렌더링 엔진이, JS는 자바스크립트 해석기가 해석함.

HTML의 역사
- 4버전이 출시 될 때(1997년) : 하드웨어적, 소프트웨어적 발전이 기하급수적으로 발전되었음.
- 그 이전에는 HTML의 문서의 양이 작고 간결할 수 밖에 없었음.(하드웨어가 딸리니...)
- 4버전부터 대용량 HTML문서가 많아짐 $\rightarrow$ 처리와 유지보수가 어려움.
- 데이터를 구조화하는 방향으로 가자고 해서, 4버전 이후 HTML을 XML화 시키자는 방향으로 하여, 4버전 이후 XHTML이 나옴.
- HTML과 달리 XML은 대소문자 구분과, 닫힘 태그가 존재함.(문법이 까다로움)
- 그래서 그 이전까지 대소문자 구분 안하던 웹개발자들이 쓰기가 어려웠고, 잘 쓰지 않았음
- 웹 2.0 패러다임(2000년대 초)이 나오면서, 웹이 플랫폼이 됨. $\rightarrow$ 웹 브라우저가 저장소의 역할이 됨. AJAX(async)과 같은 기술이 나옴. 비동기로 처리하는 기술.
- 이런 기술들을 웹브라우저들이 출시함.
- XHTML대신 각 브라우저의 종속적인 문법으로 Web2.0을 구현함.
- 웹브라우저사들의 단체(WHAT Workgroup)에서 기술에 대한 표준안을 제시
- 그래서 그 이후에야 HTML5버전이 나옴. (W3C에서 WHAT Workgroup의 표준안을 승인)
- 데이터 구조화 : 시멘틱 태그 `<header>, <section>, <article>`기능은 없고 의미만 부여.
- Web2.0기술들 : `<video>, <canvas>`
