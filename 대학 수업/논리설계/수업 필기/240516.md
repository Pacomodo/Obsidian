* Mealy FSM
Recall : 
Mealy FSM은 Input + 이전 State를 통해 Output을 결정한다.
Moore FSM은 오직 이전 State를 통해 Output을 결정한다.

헷갈리지 말자. Output과 State transition은 다르다.

1과 0이 쓰여있는 종이 위를 기는 달팽이가 있다고 하자.

* Blocking and Nonblocking
두 개의 차이점을 보자.
![[Pasted image 20240516113131.png|center|400]]
![[Pasted image 20240516113143.png|center|400]]
![[Pasted image 20240516113159.png|center|400]]
두 개는 대입 연산자인데, <=은 Nonblocking임.
동시에, 병렬적으로 일어남.
예를 들어, a <= b; c <= d;라고 하면, 두 개는 동시에 일어남.
즉, a <= b; c <= d; 나, c <= d; a <= b;나 동일한 명령임.
반면, =는 Blocking임. 순서대로 일어남.
a = b; c = d;와 c = d; a = b;라고 하면 둘은 다른 명령임.
전자는 b에 의해 a가 변한 뒤 d에 의해 c가 변한다는 의미고, 후자는 d에 의해 c가 변한 뒤 b에 의해 a가 변한다는 뜻이다.
![[Pasted image 20240516113743.png|center|400]]
예를 들어, D Flip-Flop은 Clock에 의해 "동시에" 결과가 변하므로 <= 를 사용한다.
![[Pasted image 20240516114015.png|center|400]]
N2는 N1에 의해 변하고, N3는 N2에 의해 변하고...
이걸 잘 생각해보면, 동시에 변하는 건 아니다. 그래서 = 를 사용한다.
![[Pasted image 20240516114401.png|center|400]]
두 개는 다르겠지? 왼쪽은 동시에 변하고 오른쪽은 순서대로 변함
