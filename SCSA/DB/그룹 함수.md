### 종류

- `COUNT(*)` : NULL값을 포함한 행의 수 출력
- `COUNT(표현식)` : 행의 수 출력
- `SUM([DISTINCT|ALL] 표현식)` : 합계 출력
- `AVG([DISTINCT|ALL] 표현식)` : 평균 출력
- `MAX([DISTINCT|ALL] 표현식)` : 최대값 출력
- `MIN([DISTINCT|ALL] 표현식)` : 최소값 출력
- `STDDEV([DISTINCT|ALL] 표현식)` : 표준편차 출력
- `VARIANCE([DISTINCT|ALL] 표현식)` : 분산 출력

- `COUNT(*)`를 제외한 모든 그룹함수는 널 값을 제외하고 처리
- `MAX, MIN, COUNT`는 문자, 날짜에도 적용 가능.
- `DISTINCT`는 중복되지 않는 값만 검토. 기본값은 `ALL`

### 구문

```sql
SELECT 그룹함수([DISTINCT/ALL] {COLUMN, ...})
FROM 테이블
[WHERE 조건]
[GROUP BY 컬럼1, 컬럼2, ...]
[HAVING 그룹조건]
[ORDER BY 컬럼1, 컬럼2, ...]
```
### GROUP BY 절

- 집계함수는 널 값을 제외하고 수행
- `GROUP BY`절은 별칭 사용 못함
- 집계함수는 `WHERE`절에서는 사용 못함. (집계 함수를 사용할 수 있는 `GROUP BY`절 보다 `WHERE`절이 먼저 수행된다.)
- `WHERE`절은 전체 데이터를 GROUP으로 나누기 전에 행들을 미리 제거시킨다.

### HAVING 절

- `HAVING`절을 사용하면 다음 단계를 수행한다.
	1. 행이 분류된다.(그룹 형성)
	2. 그룹 함수가 그룹에 적용된다.
	3. `HAVING`절의 조건에 일치하는 그룹이 표시된다.
