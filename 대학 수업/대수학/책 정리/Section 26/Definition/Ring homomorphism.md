___

**DEF**) A map $\phi : R \rightarrow R'$ is a **[[Ring|ring]] homomorphism** if two conditions are satiesfied for all $a, b \in R$.
* $\phi (a+b) = \phi (a) + \phi (b)$
* $\phi (ab) = \phi (a) \phi (b)$

___

**EXAMPLES**)

* **Projection Homomorphism**
Let $R_1, R_2, ..., R_n$ be rings. For each $i$, the map $\pi_i : R_1\times R_2 \times \cdots \times R_n \rightarrow R_i$ defined by $\pi_i (r_1, r_2, ..., r_n) = r_i$ is a homomorphism, _projection onto the $i$th component_.
