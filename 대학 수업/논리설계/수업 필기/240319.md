Assume that we add $a$ = $4$-bit signed, $b$ = $8$-bit signed then MSB of $a$ = 1(assume that $a$ is negative number.)
$a = 1111$, $b = 00010000$ ($a = -1, b = 16$)
if we extend $a$ using $0$-extension, $a + b = 00011111 = 31$. (wrong)
so, we need to use $1$-extension.
![[Pasted image 20240319104711.png]]
$a + b = 11111111 + 00010000 = 00001111 = 15$.
