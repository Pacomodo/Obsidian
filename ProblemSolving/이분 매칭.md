## Kuhn's Algorithm (DFS Augmenting)

**입력** : 이분 그래프 $G = (L \cup R, E)$. 간선 집합 $E$는 항상 $L\rightarrow R$ 방향.
**목표** : 매칭 $M \subseteq E$을 최대화.

* 증가 경로(Augmenting path) : 매칭에 포함되지 않은 간선과 포함된 간선이 교대로 나오며, 시작 정점과 끝 정점 모두 매칭되지 않은 경로

증가 경로를 따라 간선의 매칭 여부를 모두 뒤집어주면 매칭 크기가 $1$ 증가한다.

#### **알고리즘 순서**

편의 상 왼쪽 정점을 $u\in L$, 오른쪽 정점을 $v\in R$이라고 하자.

1. $R$ 쪽에 배열 `matchedR[v]`를 선언한다. `matchedR[v]=u`는 $v$가 $u$와 매칭되었음을 의미.
2. 매칭 안된 $u\in L$에서 시작하여 $u$와 인접한 $v$들을 순회하며 다음 과정을 진행.
	1. `matchedR[v] = -1`, 즉, $v$가 아무도 매칭되지 않은 상황이라면 바로 $u$와 매칭 후 성공 반환.
	2. `matchedR[v] = u'`, 즉, $v$가 이미 다른 $u'\in L$과 매칭되있는 상황이라면 재귀적으로 $u'$을 탐색.

#### **수도 코드(Pseudo code)**

```
Input : Adj[u] = u와 인접한 정점 v의 리스트

matchedR[v] = -1 for all v in R
matched = 0

for u in L:
	visited = [false]*|R|
	if dfs(u, visited):
		matched++

function dfs(u, visited):
	for v in Adj[u]:
		if not visited[v]:
			visited[v] = true
			if matchedR[v] == -1 or dfs(matchedR[v], visited):
				matchedR[v] = u
				return true
	return false
```
#### **정당성**

- **Berge's Theorem**
$$
\begin{gather}
\text{A matching }M \subseteq E \text{ in }G\text{ is maximum(contains the largest possible number of edges)} \\ 
\iff \\
\text{There is no augmenting paths with }M.
\end{gather}
$$
위의 알고리즘은 증가 경로를 찾는 즉시 매칭을 확장시킨다. 따라서 어떤 $u$에서도 DFS를 통해 증가 경로를 찾을 수 없다면 매칭 $M$에 증가 경로가 없다는 뜻이다. 따라서 버지 정리에 의해 매칭이 최대이다.

#### **시간 복잡도**

DFS한 번 당 최악의 경우 $\mathcal{O}(E)$이므로, $\mathcal{O}(VE)$의 시간 복잡도 소요.
해당 시복도를 해결하기 위해선 정해진 순서대로 노드를 탐색하는 것이 아니라 랜덤하게 섞어서 노드를 탐색하면 된다.

#### C++ 구현 코드

```cpp
#include <vector>
#include <algorithm> // std::shuffle
#include <random>    // std::mt19937, std::random_device
using namespace std;

struct Kuhn{
	int L, R;
	vector<vector<int>> adj;
	vector<int> matchedR;
	vector<int> visited;
	
	Kuhn(int L, int R): L(L), R(R), adj(L), matchedR(R, -1), visited(R, 0) {};
	
	void addEdge(int u, int v){
		adj[u].push_back(v);
	}
	
	bool dfs(int u){
		for (int v : adj[u]){
			if (!visited[v]){
				visited[v] = 1;
				if (matchedR[v] == -1 || dfs(matchedR[v])){
					matchedR[v] = u;
					return true;
				}
			}
		}
		return false;
	}
	
	int matching(){
		int match = 0;
		for (int u = 0; u < L; ++u){
			fill(visited.begin(), visited.end(), 0);
			if (dfs(u)){
				++match;
			}
		}
		return match;
	}
	
	vector<pair<int, int>> matchedEdges() const {
		vector<pair<int, int>> res;
		for (int v = 0; v < R; ++v){
			if (matched[v] != -1){
				res.pushback({matched[v], v});
			}
		}
		return res;
	}
}
```
