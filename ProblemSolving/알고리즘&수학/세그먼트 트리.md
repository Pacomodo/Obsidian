## 구간 합 문제

다음과 같은 문제를 생각해보자.

> 어떤 $N$개의 수가 주어져 있다.
> 그런데 중간에 수의 변경이 **빈번히** 일어나고 그 중간에 어떤 부분의 합을 구하려 한다.
> 만약에 $1,2,3,4,5$라는 수가 있고, 3번째 수를 $6$으로 바꾸고 2번째부터 5번째까지 합을 구하라고 한다면 $17$을 출력하면 되는 것이다.
> 그리고 그 상태에서 다섯 번째 수를 $2$로 바꾸고 3번째부터 5번째까지 합을 구하라고 한다면 $12$가 될 것이다.
> (출처 : https://www.acmicpc.net/problem/2042)


부분합을 빠르게 구하는 알고리즘은 우리가 잘 알고 있는 누적합 알고리즘이 있다.

누적합 배열을 $\mathcal{O}(N)$으로 전처리한 후, 구간 합을 묻는 질문(통칭 $\text{Select}$ 쿼리)에는 $\mathcal{O}(1)$에 처리할 수 있다.

하지만 $\text{Update}$ 쿼리가 껴있다면 이야기가 달라진다.

$\text{Update}$ 쿼리가 껴있다면 결국 누적합 배열을 **다시** 만들어야 한다.

따라서, $\text{Update}$ 쿼리와 $\text{Select}$ 쿼리가 교대로 나오는 최악의 상황에는, 처음부터 끝까지 하나씩 더하는 경우랑 다를 바가 없게 된다. (즉, 매 쿼리마다 $\mathcal{O}(N)$의 시간이 소요된다는 뜻이다.)

이때 세그먼트 트리라는 자료구조를 이용하면 $\text{Update}$ 쿼리를 $\mathcal{O}(\log N)$, $\text{Select}$ 쿼리를 $\mathcal{O}(\log N)$으로 해결할 수 있다.

#### C++ 구현

먼저, 트리 구조를 표현할 1차원 배열 `tree`를 선언하자.
```cpp
    int n;
    vector<long long> tree;
    
    Segtree(int data_size): n(data_size), tree(4*data_size, 0) {};
```
`tree`의 크기는 보통 (데이터의 크기)$\times$ 4로 잡는 것이 일반적이다. (https://www.acmicpc.net/board/view/79441 참조)

```cpp
    void build(const vector<long long>& arr){
        build(arr, 1, 0, n);
    }
    // 반열린 구간을 기준으로 build. [l, r)구간의 합을 i번째에 저장한다는 뜻.
    void build(const vector<long long>& arr, int i, int l, int r){
        if (l + 1 == r){
            if (l < arr.size()) tree[i] = arr[l];
            return;
        }
        int mid = (l+r) >> 1;
        build(arr, i << 1, l, mid);
        build(arr, (i << 1)|1, mid, r);
        tree[i] = tree[i << 1] + tree[(i << 1)|1];
    }
```
트리를 구성하는 `build(arr)`는, 인자로 `arr`를 받아서 `tree`를 구성한다.
`build(arr, i, l, r)`은 `[l, r)`의 반열린 구간의 합을 $i$번째에 저장하는 코드이다.

`build(arr)`는 `build(arr, 1, 0, n)`을 호출한다. 즉, $1$번 노드에 `[0, n)`구간의 합을 저장하려 한다.

재귀적으로 봤을 때 $1$번 노드는 $2$번 노드와 $3$번 노드의 합으로 이루어져 있으므로,
`tree[i] = tree[i << 1] + tree[(i << 1)|1];`라는 코드가 나온다.

그 이전에 `tree[i << 1]`와 `tree[(i << 1)|1]`가 정의되어있어야 하므로 재귀호출을 다음과 같이 진행해야한다.

```cpp
        int mid = (l+r) >> 1;
        build(arr, i << 1, l, mid);
        build(arr, (i << 1)|1, mid, r);
        tree[i] = tree[i << 1] + tree[(i << 1)|1];
```
 재귀호출이 종료되는 조건은 구간의 길이가 $1$일 때이다.
 ```cpp
         if (l + 1 == r){
            if (l < arr.size()) tree[i] = arr[l];
            return;
        }
 ```

비슷하게, `select`함수는 다음과 같이 작성할 수 있다.
```cpp
    long long select(int l, int r){
        return select(1, 0, n, l, r);
    }
    long long select(int i, int l, int r, int ql, int qr){
        if (qr <= l || r <= ql) return 0; // 구간 질의에 포함되지 않는 경우
        if (ql <= l && r <= qr) return tree[i]; // 포함하는 경우
        int mid = (l+r) >> 1;
        return select(i << 1, l, mid, ql, qr) + select((i << 1)|1, mid, r, ql, qr);
    }
```
`select(i, l, r, ql, qr)`은 현재 `[l, r)`구간을 보고 있고, 질의로 들어온 구간이 `[ql, qr)`이라는 뜻이다.

만약 현재 구간이 구간 질의에 포함된다면 `tree[i]`를 반환하면 된다.
만약 현재 구간이 구간 질의에 포함되지 않는다면 $0$을 반환하면 된다.
그 외의 경우, 현재 구간을 절반으로 쪼개서 두 구간의 합을 반환하면 된다.

`update`함수는 다음과 같이 작성할 수 있다.
```cpp
    void update(int idx, long long val){
        update(1, 0, n, idx, val);
    }
    void update(int i, int l, int r, int idx, long long val){
        if (idx < l || r <= idx) return;
        if (l + 1 == r){
            tree[i] = val;
            return;
        }
        int mid = (l+r) >> 1;
        update(i << 1, l, mid, idx, val);
        update((i << 1) | 1, mid, r, idx, val);
        tree[i] = tree[i << 1] + tree[(i << 1)|1];
    }
```
`update(i, l, r, idx, val)`은 `tree[i]`를 `a[idx] = val`에 맞춰 업데이트 하는 코드이고 `build`와 비슷하게 코드를 구성할 수 있다.



전체 코드는 다음과 같다.
```cpp
#include <vector>
using namespace std;

    }
    // 반열린 구간을 기준으로 build. [l, r)구간의 합을 i번째에 저장한다는 뜻.
    void build(const vector<long long>& arr, int i, int l, int r){

    }

    long long select(int l, int r){
        return select(1, 0, n, l, r);
    }
    long long select(int i, int l, int r, int ql, int qr){
        if (qr <= l || r <= ql) return 0; // 구간 질의에 포함되지 않는 경우
        if (ql <= l && r <= qr) return tree[i]; // 포함하는 경우
        int mid = (l+r) >> 1;
        return select(i << 1, l, mid, ql, qr) + select((i << 1)|1, mid, r, ql, qr);
    }
    
    void update(int idx, long long val){

    }
    void update(int i, int l, int r, int idx, long long val){
```

## 모노이드(Monoid)

세그먼트 트리를 일반적인 구조로 확장시킬 수 있다.

구간 합 구하기 문제를 봤을 때, 구간을 벗어났을 때 $0$을 반환했었고, 여러 구간이 있을 때 왼쪽 구간들을 더하고 오른쪽 구간들을 더하던지, 왼쪽 구간들을 더하고 거기에 오른쪽 구간을 더하던지와 상관 없이 항상 같은 구간 합이 나왔음을 생각해보자.

이제 이런 구조를 가진 모든 대상들을 생각하자.

집합 $G \neq \varnothing$ 위에 이항 연산 $\circ$ 이 정의되어 있고, 임의의 원소 $a, b, c \in G$에 대해 다음 2가지 성질이 성립할 때 $(G, \circ)$를 **모노이드** 라고 하고, "$G$는 연산 $\circ$에 관하여 모노이드를 이룬다,"라고 말한다.

1. $(a\circ b)\circ c = a \circ (b \circ c)$ (결합 법칙)
2. 특정한 원소 $e\in G$가 존재하여, 모든 원소 $a \in G$에 대해 등식 $a \circ e = e \circ a = a$가 성립한다.

원소 $e$를 $G$의 연산 $\circ$에 관한 **항등원(恒等元, Identity)** 라고 한다.

#### 예시

- $(\mathbb{Z}, +)$: 정수 집합 $\mathbb{Z}$와 덧셈. $e = 0$
- $(\mathbb{Z}, \times)$: 정수 집합 $\mathbb{Z}$와 곱셈. $e = 1$
- $([S, E], \max)$: 주어진 임의의 구간 $[S, E]$와 $\max$연산. $e = -\infty$
- $([S, E], \min)$: 주어진 임의의 구간 $[S, E]$와 $\min$연산. $e = \infty$
- $(\mathbb{Z}^{+}, \text{xor})$: 양의 정수 집합 $\mathbb{Z}^{+}$와 $\text{xor}$연산. $e = 0$
- $(\mathbb{Z}^{+}, \text{and})$: 양의 정수 집합 $\mathbb{Z}^{+}$와 $\text{and}$연산. $e = 11\dots 1_{2}$
- $(\mathbb{Z}^{+}, \text{or})$: 양의 정수 집합 $\mathbb{Z}^{+}$와 $\text{or}$연산. $e = 00\dots 0_{2}$
- $(\mathbb{Z}^{+}, \gcd)$: 양의 정수 집합 $\mathbb{Z}^{+}$와 $\gcd$연산. $e = 0$
- $(\mathbb{Z}^{+}, \text{lcm})$: 양의 정수 집합 $\mathbb{Z}^{+}$와 $\text{lcm}$연산. $e = 1$
- $(S, +)$: 문자열 집합 $S$와 두 문자열을 Concat하는 연산 $+$. $e = \text{`` ''}$(빈 문자열)
- $(U, \cup)$: 집합 $U$와 합집합 연산 $\cup$. $e = \varnothing$(공집합)
- $(U, \cap)$: 집합 $U$와 교집합 연산 $\cap$. $e = U$(전체 집합)

#### 모노이드의 결합

두 모노이드 $(S, \circ), (S', \circ')$이 주어져있다면 두 모노이드를 다음과 같이 Direct product한 결과 또한 모노이드이다.

- 집합 : $S\times S'$
- 연산 : $(s_{1}, s'_{1})\oplus (s_{2}, s'_{2}) = (s_{1}\circ s_{2}, s'_{1}\circ ' s'_{2})$

즉, 성분 별로 각각의 연산을 따로 적용하여 새로운 연산을 정의한다면 항등원은 $e = (e_{s}, e_{s'})$이 된다.

예를 들어, $([S, E], \max)$ 모노이드와 $([1, n], \max)$모노이드를 결합하여 새로운 모노이드를 만들 수 있다.

이때의 항등원 $e = (S-1, 0)$이 될 것이다. 즉, 구간 별 최댓값과 그때의 인덱스를 "묶어서" 생각하는 것 또한 가능하다는 뜻이다.

## 일반화된 세그먼트 트리

따라서 어떤 구조가 모노이드를 이룬다면 모두 세그먼트 트리로 해결할 수 있다.

$+$ 연산자를 오버라이딩하여 새롭게 정의하고, 항등원 $e$또한 $0$대신 해당 모노이드 구조에 맞게 오버라이딩 하면 된다.

#### C++ 구현

`Element`구조체를 추가하여 구현한 C++코드는 아래와 같다. 연산자 오버라이딩과 `id`에 주목하자.
```cpp
#include <vector>
using namespace std;

struct Element {
    long long v;
    
    Element() : v(id().v) {}          // 기본 생성자: id()의 v값으로 초기화
    Element(long long _v) : v(_v) {}  // 값 지정 생성자

    static Element id() {
        return Element(0);
    }

    Element operator+ (const Element& other) const {
        return Element(v + other.v);
    }
};

struct Segtree {
    int n;
    vector<Element> tree;

    Segtree(int data_size): n(data_size), tree(4*data_size) {};

    void build(const vector<Element>& arr){
        build(arr, 1, 0, n);
    }
    // 반열린 구간을 기준으로 build. [l, r)구간의 합을 i번째에 저장한다는 뜻.
    void build(const vector<Element>& arr, int i, int l, int r){
        if (l + 1 == r){
            if (l < arr.size()) tree[i] = arr[l];
            return;
        }
        int mid = (l+r) >> 1;
        build(arr, i << 1, l, mid);
        build(arr, (i << 1)|1, mid, r);
        tree[i] = tree[i << 1] + tree[(i << 1)|1];
    }

    Element select(int l, int r){
        return select(1, 0, n, l, r);
    }
    Element select(int i, int l, int r, int ql, int qr){
        if (qr <= l || r <= ql) return Element::id(); // 구간 질의에 포함되지 않는 경우
        if (ql <= l && r <= qr) return tree[i]; // 포함하는 경우
        int mid = (l+r) >> 1;
        return select(i << 1, l, mid, ql, qr) + select((i << 1)|1, mid, r, ql, qr);
    }

    void update(int idx, Element val){
        update(1, 0, n, idx, val);
    }
    void update(int i, int l, int r, int idx, Element val){
        if (idx < l || r <= idx) return;
        if (l + 1 == r){
            tree[i] = val;
            return;
        }
        int mid = (l+r) >> 1;
        update(i << 1, l, mid, idx, val);
        update((i << 1) | 1, mid, r, idx, val);
        tree[i] = tree[i << 1] + tree[(i << 1)|1];
    }
};
```

## 응용

#### Inversion Counting

문제 : Counting Inversion (https://www.acmicpc.net/problem/10090)

어떤 배열 $a$에 대해서 `a[x] > a[y], x < y`인 `(x, y)`쌍의 개수를 모두 세는 문제이다.

예를 들어, 다음과 같은 배열이 있다고 해보자.
$$
[4, 2, 7, 1, 5, 6, 3]
$$
이 경우, $4-2$, $4- 1$, $4 -3$, $2-1$, $7-1$, $7-5$, $7-6$, $7-3$, $5-3$, $6-3$, 총 $10$쌍이 나온다.


- 일반적인 완탐의 경우? $\mathcal{O}(N^{2})$...
- 하지만 다음과 같이 세그먼트 트리로 $\mathcal{O}(N\log N)$으로 해결 할 수 있다.

위의 예시의 경우

- $4$를 넣음
- $[0, 0, 0, 1, 0, 0, 0], ans = 0$
- $2$를 넣으면서 동시에 질의($2$보다 큰 애들이 몇 개임? -> 3~8 구간 합 질의 -> 1)
- $[0, 1, 0, 1, 0, 0, 0], ans = 1$
- $7$을 넣으면서 동시에 질의($7$보다 큰 애들 몇 개임? -> 없음...)
- $[0, 1, 0, 1, 0, 0, 1], ans=1$
- $1$을 넣으면서 동시에 질의($1$보다 큰 애들 몇 개임? -> 2~8 구간 합 질의 -> 3)
- $[1, 1, 0, 1, 0, 0, 1], ans = 4$
- 반복...

#### 구간 업데이트, 점 질의

문제 : 수열과 쿼리 21 (https://www.acmicpc.net/problem/16975)

- 세그먼트 트리는 구간 질의, 점 업데이트를 지원하는 자료구조
- 반대로 위의 문제처럼 구간 업데이트, 점 질의가 이뤄지면 어떻게 할 수 있을까?
- 레이지 세그라는 자료구조로도 해결할 수 있지만, 아직 해당 자료구조를 배우지 않았으므로 기본 세그로 해결하는 방법을 배워보자.

- 본 문제를 해결하기 이전에 다음 문제를 해결해보자.

문제 : 시간이 겹칠까? (https://www.acmicpc.net/problem/28018)

- 일반적인 방법으로 누적합 배열을 만들려고 한다면? $\rightarrow$ 구간의 범위가 매우 큼... 일반적인 방법으로 누적합 배열을 만들 수 없다.
- 또 다른 배열 $B$를 하나 만들어서 해당 배열에 구간이 시작하는 곳에 $+1$를, 구간이 끝나는 곳에 $-1$를 해주도록 하자.
- 이후 $B$를 순회하며 누적합 배열을 만들어주면 된다.



- 이 $B$를 **차분 배열(Difference Array)** 이라고 하는데, 해당 배열을 세그먼트 트리로 관리하면 16975번을 해결할 수 있다.
