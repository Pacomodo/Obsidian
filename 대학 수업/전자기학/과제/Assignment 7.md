##### Problem 1
The electric field in free space is given by $$\mathbf{E}(x,y,z,t) = (10\mathbf{a}_{y}+5\mathbf{a}_{z})\cos(\omega t+2y-4z)[\text{V/m}]$$ Find the wave length along the direction of propagation. Note that the wavelength is the distance over which the phase changes by $2\pi$ radians for a fixed value of time. Use the fact that the distance between the two planes, $$\begin{align}ax+by+cz=d_{1}\\ax+by+cz=d_{2}\end{align}$$ is given by $$\frac{\lvert d_{2}-d_{1} \rvert }{\sqrt{ a^{2}+b^{2}+c^{2} }} $$ if necessary.
___
Sol)
The plane perpendicular to the direction of the propagation is $-2y+4z = d_{1}$.
Since $\lambda$ is distance over which the phase changes by $2\pi \text{ rad}$ for a fixed $t$, Let $d_{1} = d_{1}, d_{2} = d_{1} + 2\pi$.
Then,
$$
\lambda = \frac{2\pi}{\sqrt{ (-2)^{2}+4^{2} }} = \frac{2\pi}{2\sqrt{ 5 }} = \frac{\pi}{\sqrt{ 5 }}\text{[m]}
$$
