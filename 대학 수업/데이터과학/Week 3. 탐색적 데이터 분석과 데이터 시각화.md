### 공공데이터 품질 관리와 오류율

#### 데이터 품질 지표 DQI

1. 일관성 - 데이터 품질 오류율의 **표준 오류율**과 직결됨.
개체의 속성이 표준을 준수하는가? 중복되지 않는가? 데이터 연계에 있어 일관성이 유지되고 있는가?
세부지표 - 속성, 표준, 중복값, 연계값
2. 완전성 - 데이터 품질 오류율의 **구조 오류율**과 직결됨.
데이터베이스 구축에 있어 논리적 설계, 물리적 구조가 올바르게 구축되었는가?
세부지표 - 논리모델, 식별자, 물리구조, 속성의미
3. 정확성 - 데이터 품질 오류율의 **값 오류율**과 직결됨.
데이터가 유효한 범위에 있는가? 형식으로 구성되어있는가?
세부지표 - 입력값, 업무규칙, 범위,형식, 참조관계, 계산식

그러면 일관성과 정확성의 차이점?
예를 들어, 월/일을 입력하는데 13월 12일을 입력하면 오류임.(정확성), 여러 전화 번호의 표기 방식 01012345678, 010-1234-5678 등 여러 있지만 이 중 표준은 하나(일관성)

4. 준비성
데이터 품질 관리 정책 및 지침이 기관에 맞게 잘 정의되있는가?
경영자, 의사결정권자가 데이터 품질 관리 필요성을 이해하고 있는가?

5. 보안성
DBMS가 자연재해에 대비되어있는가?
저작권, 개인정보등 비공개 대상 정보를 파악하여 관리하고 있는가?

6. 적시성
데이터 갱신 주기와 방법이 명시적으로 정의되어 있는가?
데이터 별 응답시간 기준이 마련되어 있는가?

7. 유용성
만족할 정도로 충분한 정보가 제공되고 있는가?
접근하기에 편의한가?

#### 데이터 품질 오류율 산정
품질 오류율 = $0.7E_{값}+0.2E_{표준}+0.1E_{구조}$
예를 들어, 값 오류율이 20%, 표준 오류율이 10%, 구조 오류율이 30%이라고 하자.
그러면, 14% + 2% + 3% = 19%이다.
AHP기법을 이용하여 저 가중치가 산정되었음.
* 값 오류율
오류 데이터 건수 / 전체 데이터 건수 
* 표준 오류율
표준 오류율 측정을 위한 진단 항목 별 오류율의 산술평균
A항목에서 4%, B항목에서 6%면 표준 오류율은 5%.
* 구조 오류율
표준 오류율 계산 방식과 동일.

#### Boxplot과 Interquartile Range
![[Pasted image 20240422041944.png]]
* IQR = Interquartile Range = Q3 - Q1
즉, 주어진 데이터 셋 내의 데이터의 절반이 IQR의 범위 내에 분포.
이 그림의 경우 정규분포는 아님.
Box-and-whisker 도식을 통해 데이터의 분포를 한눈에 파악할 수 있음.
평균, 최빈값등의 통계량을 이 도식에서 도출해낼 수는 없음.
특정 데이터가 이상치에 해당하는지 판단하는 기준은?
IQR을 기준으로 판단.

#### IQR을 이용한 이상치 구분
* Tukey's Fences.
Q3와의 차이가 1.5IQR을 초과할 만 큼 큰 값, 혹은 Q1과의 차이가 1.5IQR을 초과할 만 큼 작은 값은 이상치로 간주.
* Carling's Modification
Median과의 차이가 2.3IQR을 초과하는 값은 이상치로 간주. Q1Q3의 위치를 고려하지 않는다.

#### 정규분포와 3$\sigma$규칙
* 정규분포 하에서 99.7%의 데이터는 평균에서 3$\sigma$내에 위치함. $\to$ 평균과 3$\sigma$넘게 떨어져 있는 모든 데이터를 이상치로 간주.
68.3%정도의 데이터가 1$\sigma$, 95.5%정도의 데이터는 2$\sigma$정도의 데이터, 99.7정도의 데이터가 3$\sigma$.
정규 분포에서 고안된 규칙이지만, 정규 분포가 아니더라도 적용할 수 있다.

#### 다 같은 결측치가 아니다
* MCAR (missing completely at random)
결측치가 특정 변수와 "관계없이" "무작위"로 발생한 경우.
Age가 MCAR결측치
* MAR (missing at random)
다른 변수와 연관되어 결측치가 발생한 경우.
Lane이 MAR결측치. 성별이 여성 $\to$ 결측.
* MNAR (missing not at random)
변수 스스로와 연관되어 결측치가 발생한 경우
예를 들어, 티어가 빠진 두 명의 티어가 브론즈라면? 스스로와 연관됨.

#### 삭제를 이용한 결측치 처리

* Listwise Deletion
결측치가 하나라도 존재하는 행을 제거
* Column Drop
결측치가 일정 비율 이상인 열을 제거. 이 일정비율은 사용자가 직접 지정함.
* Pairwise Deletion
분석 모델에 투입되는 **행**들에 대하여 결측치가 하나라도 존재하는 행을 제거.

#### k-최근접 이웃 방법에 기초한 결측치 대체
* 가중치를 고려하지 않는 $k$-NN방법
2번 데이터와 가장 가까운 데이터는 3-1-4
$k=1$이면 가장 가까운 3번 데이터의 $X_{1}$값인 250으로 대체
$k=2$이면 가장 가까운 3번과 1번 데이터의 $X_{1}$의 평균인 175로 대체.
$k=3$이라면 전체 평균이랑 별 다를바가 없다.
다른 변수들을 고려한다는 점에서 좋다.

* 가중치를 고려하는 $k$-NN방법
$k=2$로 두면 가장 가까운 3번과 1번의 **가중 평균**으로 결측치 대체.
기존 방법
$$
\frac{x_{3}+x_{1}}{2}
$$
가중치 방법
$$
\frac{\frac{x_{3}}{d_{3}}+\frac{x_{1}}{d_{1}}}{\frac{1}{d_{3}}+\frac{1}{d_{1}}}
$$
