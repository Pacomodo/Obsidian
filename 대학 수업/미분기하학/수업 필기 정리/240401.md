___
>[!Recall]
>[[240325#^2a0405|Definitions]] of $\mathbf{T}, \mathbf{N}, \mathbf{B}, \kappa, \tau$

For $\beta(s)$ : **unit speed** space curve ($||\beta'(s)|| = 1$)
$$\mathbf{T}(s) = \beta'(s)$$
$$\kappa(s) = ||\mathbf{T}'(s)|| = ||\beta''(s)|| (\textrm{curvature})$$
$$\mathbf{N}(s) = \frac{\mathbf{T}'(s)}{\kappa(s)} (\kappa(s) > 0)$$
$$\mathbf{B}(s) = \mathbf{T}(s) \times \mathbf{N}(s)$$
$$\tau(s) = -{<}\mathbf{B}'(s), \mathbf{N}(s){>}(\textrm{torsion})$$

___

**RECALL**: For each $s$, $\{\mathbf{T}(s), \mathbf{N}(s), \mathbf{B}(s)\}$ forms ONB. We call $\mathbf{T}, \mathbf{N}, \mathbf{B}$ as **frame field**(틀장).
This frame is moving frame.

F-S Formula : $$\begin{pmatrix} \mathbf{T} \\ \mathbf{N} \\ \mathbf{B} \end{pmatrix}' = \begin{pmatrix} 0 & \kappa & 0\\ -\kappa & 0 & \tau \\ 0 & -\tau & 0 \end{pmatrix}\begin{pmatrix} \mathbf{T} \\ \mathbf{N} \\ \mathbf{B} \end{pmatrix}$$
___

**RECALL**: We want to make $\kappa$ and $\tau$ when the curve is not unit speed.
![[Pasted image 20240401140714.png|center|400]]
So, we use $\alpha(t) = \beta(s(t))$.

$$\frac{\mathrm{d}\alpha}{\mathrm{d}t} = \frac{\mathrm{d}\beta}{\mathrm{d}s}\frac{\mathrm{d}s}{\mathrm{d}t} = \mathbf{T}||\alpha'||$$

So, for arbitrary speed curve $\alpha(t)$,
$$\mathbf{T}(t) = \frac{\alpha'(t)}{||\alpha'(t)||}$$
$$\kappa(t) = \frac{||\alpha' \times \alpha''||}{||\alpha'||^3}$$
$$\tau(t) = \frac{{<}\alpha'\times\alpha'', \alpha'''{>}}{||\alpha'\times\alpha''||^2}$$

___

In this time, we want to find the relation between $\kappa$ and $\tau$.

___

Suppose $\beta(s)$: unit speed curve is given.
Consider $\mathbf{T}(s) = \beta'(s)$.
![[Pasted image 20240401190653.png|center|400]]
In this figure, green arrow shows $\mathbf{T}(s)$.
Move all start position of green arrows into origin.
![[Pasted image 20240401191057.png|center|400]]
Since $\mathbf{T}$ is unit vector, end points of all vectors on a unit sphere.
Here, we will define $\gamma_\beta(s)$.

>[!note] Definition
$$\gamma_\beta(s) = \mathbf{T}(s)$$
Here, $\gamma_\beta(s)$ is a curve on a **unit** sphere. (c.f. spherical curve)

So, why are we doing this?

___

**EXAMPLE**)
Consider $\alpha(t) = (a\cos t, a\sin t, bt)$ where $a > 0, b > 0$.
Note that $\alpha(t)$ is **circular helix**.
![[Pasted image 20240401223011.png|center|400]]
Reparametrize $\alpha(t)$ using arc length function.
$$\beta(s) = \left(a\cos(\frac{s}{\sqrt{a^2+b^2}}),a\sin(\frac{s}{\sqrt{a^2+b^2}}),b\frac{s}{\sqrt{a^2+b^2}}\right)$$
We defined $\gamma_\beta(s) = \mathbf{T}(s)$,
$$\mathbf{T}(s) = \gamma_\beta(s) = \left(-\frac{a}{\sqrt{a^2+b^2}}\sin(\frac{s}{\sqrt{a^2+b^2}}),\frac{a}{\sqrt{a^2+b^2}}\cos(\frac{s}{\sqrt{a^2+b^2}}),\frac{b}{\sqrt{a^2+b^2}}\right)$$
We can find that $||\gamma_\beta(s)|| = ||\mathbf{T}(s)|| = 1$, but $||\gamma'_\beta(s)|| = ||\mathbf{T}'(s)|| = \kappa(s) \neq 1$.
It means the speed of $\gamma_\beta(s)$ is not unit speed.

1. We can deduce $\gamma_\beta(s) = \mathbf{T}(s)$ from $\beta(s)$. Since $||\gamma_\beta(s)|| = 1$, $\gamma_\beta(s)$ is **spherical curve** (= on a unit sphere). But it is **not unit speed**.

2. So, we have to use $\frac{||\gamma'_\beta \times \gamma''_\beta||}{||\gamma'_\beta||^3}$ to find the curvature of  $\gamma_\beta(s)$.

3. Then, what is tangent vectors of $\gamma_\beta(s)$?
![[Pasted image 20240402112349.png|center|400]]
$$\gamma_\beta(s) = \left(-\frac{a}{\sqrt{a^2+b^2}}\sin(\frac{s}{\sqrt{a^2+b^2}}),\frac{a}{\sqrt{a^2+b^2}}\cos(\frac{s}{\sqrt{a^2+b^2}}),\frac{b}{\sqrt{a^2+b^2}}\right)$$
Note that $\gamma_\beta(s)$ is on the **unit sphere** and on **$z = \frac{b}{\sqrt{a^2+b^2}}$**.
![[Pasted image 20240402142801.png|center|300]]
So, $\gamma_\beta(s)$ is a (part of) circle with radius $\frac{a}{\sqrt{a^2+b^2}}$.
Also, the angle between $\gamma_\beta(s)$ & $(0,0,1)$ will be **constant**.
$$\cos\theta = \frac{\gamma_\beta(s)\cdot(0,0,1)}{||\gamma_\beta(s)||\cdot||(0,0,1)||} = \frac{b}{\sqrt{a^2+b^2}}$$
We can generalize **helix** using this.

>[!note] Definition
>A space curve $\alpha(t)$ is called a **generalized helix(cylidrical helix)** if there is a unit constant vector $\mathbf{u}$ such that ${<}\mathbf{T}(t), \mathbf{u}{>} = \cos\theta$ for some constant $\theta$.

Here, we consider **cylinder** as generialized view.
For example, $(x, x^2, z)$ can be also considered as cylinder.
![[Pasted image 20240402164126.png|center|400]]

We can find the curvature of $\gamma_\beta(s)$, $\kappa_{\gamma_\beta}(s)$.
Surprisingly, we can find this relation. (This is [[0401 class activity]])
$$\kappa_{\gamma_\beta}^2(s) = 1+\left(\frac{\tau(s)}{\kappa(s)}\right)^2 \textrm{where }\tau(s), \kappa(s)\textrm{ are torsion, curvature of }\beta(s)$$
$$\begin{cases}
\kappa(s) = \frac{a}{a^2+b^2}\\
\tau(s) = \frac{b}{a^2+b^2}
\end{cases}$$
___

We will generalize this relation.

___

**THEOREM**)
Let $\beta(s)$ : unit speed curve and $\gamma_\beta(s) = \mathbf{T}(s)$ is spherical curve deduced from $\beta(s)$.
Then, the curvature $\kappa_{\gamma_\beta}(s)$ of $\gamma_\beta(s)$ $$\kappa_{\gamma_\beta}(s)=\sqrt{1+\left(\frac{\tau(s)}{\kappa(s)}\right)^2}$$
where $\tau(s) =$ torsion of $\beta(s)$ and $\kappa(s) =$ curvature of $\beta(s)$.

___

**PROOF**)
Let $\mathbf{T}, \mathbf{N}, \mathbf{B}, \kappa, \tau$ are made from $\beta(s)$.
Because we don't know whether $\gamma_\beta(s)$ is unit speed or not, we need to use curvature formula for arbitrary speed.
$$\kappa_{\gamma_\beta} = \frac{||\gamma' \times \gamma''||}{||\gamma'||^3} (\textrm{for convenience, }\gamma_\beta = \gamma)$$
Let's compute $||\gamma' \times \gamma''||$.
$$\gamma' = \mathbf{T}' = \kappa\mathbf{N}(\because\textrm{F-S})$$
$$\begin{align}
\gamma'' &= (\kappa\mathbf{N})'\\
&= \kappa'\mathbf{N} + \kappa\mathbf{N}'\\
\xrightarrow{\textrm{F-S Formula}}
&= \kappa'\mathbf{N} + \kappa(-\kappa\mathbf{T} + \tau\mathbf{B})\\
&= (-\kappa)^2\mathbf{T} + \kappa'\mathbf{N} + \kappa\tau\mathbf{B}
\end{align}$$
$$\begin{align}
\gamma' \times \gamma'' &= (\kappa\mathbf{N})\times((-\kappa)^2\mathbf{T} + \kappa'\mathbf{N} + \kappa\tau\mathbf{B})\\
\xrightarrow{\times\textrm{ is distributable}}
&= -\kappa^3(\mathbf{N}\times\mathbf{T}) + \kappa^2\tau(\mathbf{N}\times\mathbf{B})\\
&= \kappa^3\mathbf{B} + \kappa^2\tau\mathbf{T}\\
&= \kappa^2(\tau\mathbf{T}+\kappa\mathbf{B})\\
\end{align}$$
$$\begin{align}
\therefore||\gamma'\times\gamma''|| 
&= ||\kappa^2||||\tau\mathbf{T}+\kappa\mathbf{B}||\\
&= \kappa^2\sqrt{\tau^2 + \kappa^2}
\end{align}$$
Let's compute $||\gamma'||^3$.
$$||\gamma'||^3 = ||\kappa\mathbf{N}||^3 = \kappa^3$$
Therefore,
$$\Rightarrow \frac{||\gamma' \times \gamma''||}{||\gamma'||^3}
= \frac{\kappa^2\sqrt{\tau^2 + \kappa^2}}{\kappa^3}
= \sqrt{1+\left(\frac{\tau(s)}{\kappa(s)}\right)^2}$$
Note that $\sqrt{1+\left(\frac{\tau(s)}{\kappa(s)}\right)^2} \geq 1$.

___

**THEOREM**)
Let $\beta(s)$ be a **spherical unit speed** curve on a sphere with radius $a$.
Then, $$\kappa \geq \frac{1}{a}$$
___

**PROOF**)
We know that $||\beta(s)||^2 = a^2$ for all $s$.($\because \beta(s)$ is a spherical curve)
$$\begin{align}
||\beta(s)||^2 
&={<}\beta(s),\beta(s){>}= a^2\\
\xrightarrow{\frac{\mathrm{d}}{\mathrm{d}s}}
\frac{\mathrm{d}}{\mathrm{d}s}{<}\beta(s),\beta(s){>}
&= {<}\beta'(s),\beta(s){>} + {<}\beta(s),\beta'(s){>}\\
&= 2{<}\mathbf{T}(s),\beta(s){>} =0\\
\end{align}$$
$$\Rightarrow\mathbf{T}(s) \perp \beta(s) \textrm{ for all }s$$
$$\begin{align}
{<}\mathbf{T}(s),\beta(s){>} &= 0\\
\xrightarrow{\frac{\mathrm{d}}{\mathrm{d}s}}
\frac{\mathrm{d}}{\mathrm{d}s}{<}\mathbf{T}(s),\beta(s){>}
&= {<}\mathbf{T}'(s),\beta(s){>} + {<}\mathbf{T}(s),\beta'(s){>}\\
\xrightarrow{\textrm{F-S Formula}}
&= \kappa{<}\mathbf{N}(s),\beta(s){>} + {<}\mathbf{T}(s),\mathbf{T}(s){>} =0\\
\end{align}$$
$$\Rightarrow \kappa{<}\mathbf{N}(s),\beta(s){>} = -1 \textrm{ for all }s$$
$$\begin{align}
\kappa &= -\frac{1}{{<}\mathbf{N}(s),\beta(s){>}}\\
\rightarrow {<}\mathbf{N}(s),\beta(s){>} &= ||\mathbf{N}(s)||\cdot||\beta(s)||\cdot\cos\theta\\
&= a \cos\theta\\
\rightarrow \kappa &\geq \frac{1}{a}
\end{align}$$
So, $\kappa$ becomes **minimum** when $\kappa = \frac{1}{a}$.
In other words, $\beta$ is a (part of) circle with radius $a$.

___

**THEOREM**)
Let $\alpha(t)$ be a space curve and curvature $\kappa > 0$ of $\alpha$ is given.
Then,
$$\alpha(t) = \textrm{Generalized Helix} \iff \frac{\tau}{\kappa} = (\textrm{constant})$$
In other words, there is a unit vector $\mathbf{u}$ such that ${<}\mathbf{T}(t), \mathbf{u}{>} = \cos\theta$ for some constant $\theta$ if and only if $\frac{\tau(t)}{\kappa(t)} = c$ for some constant $c$.

___

**PROOF**)
Assume that reparametrization of $\alpha(t)$ with arc length function $s$ is $\beta(s)$.($\beta(s)$ is unit speed)
$(\Rightarrow)$ Suppose there are unit constant vector $\mathbf{u}$ and constant $\theta$ such that ${<}\mathbf{T}, \mathbf{u}{>} = \cos\theta$.
$$\begin{align}
{<}\mathbf{T}, \mathbf{u}{>} &= \cos\theta\\
\xrightarrow{\frac{\mathrm{d}}{\mathrm{d}s}}
{<}\mathbf{T}', \mathbf{u}{>} + {<}\mathbf{T}, \cancelto{\mathbf{0}}{\mathbf{u}'}{>} &= 0\\
\xrightarrow{\textrm{F-S Formula}}
\kappa{<}\mathbf{N}, \mathbf{u}{>} &= 0\\
\xrightarrow{\kappa > 0}
{<}\mathbf{N}, \mathbf{u}{>} &= 0\\
\leadsto \mathbf{N} &\perp \mathbf{u}
\end{align}$$
So, $\mathbf{u}$ is on the plane made by $\mathbf{T}$ and $\mathbf{B}$.
So, we can express $\mathbf{u}$ as a linear combination of $\mathbf{T}$ and $\mathbf{B}$.
$$
\leadsto \mathbf{u} = p\mathbf{T} + q\mathbf{B} \textrm{ where }p\textrm{ and }q\textrm{ are coefficients}
$$
Since $p = {<}\mathbf{T}, \mathbf{u}{>} = \cos\theta$ and $\mathbf{u}$ is unit vector, $q = \sin\theta$.
$$
\begin{align}
\mathbf{u} &= (\cos\theta)\mathbf{T} + (\sin\theta)\mathbf{B}\\
\xrightarrow{\frac{\mathrm{d}}{\mathrm{d}s}, \textrm{ F-S Formula}}
\mathbf{0} &= \kappa(\cos\theta)\mathbf{N} - \tau(\sin\theta)\mathbf{N}\\
\rightarrow
\mathbf{0} &= \mathbf{N}(\kappa\cos\theta - \tau\sin\theta)\\
\xrightarrow{\mathbf{N}\neq\mathbf{0}}
\kappa\cos\theta &= \tau\sin\theta\\
\rightarrow
\frac{\tau}{\kappa} &= \cot\theta \textrm{ (constant)}
\end{align}
$$
