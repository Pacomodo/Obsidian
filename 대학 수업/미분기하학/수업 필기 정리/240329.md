___

**RECALL:** For $\beta(s)$ : unit speed curve, **F-S(Frenet-Serret) Formula** is defined by this.

$$\begin{pmatrix} \mathbf{T} \\ \mathbf{N} \\ \mathbf{B} \end{pmatrix}' = \begin{pmatrix} 0 & \kappa & 0\\ -\kappa & 0 & \tau \\ 0 & -\tau & 0 \end{pmatrix}\begin{pmatrix} \mathbf{T} \\ \mathbf{N} \\ \mathbf{B} \end{pmatrix}$$

___

**Claim**: $\beta(s)$(Unit speed curve) is **COMPLETELY** determined by $\kappa(s)$ & $\tau(s)$.

___

**THEOREM**)
Let $\beta(s)$ & $\beta ^*(s)$ be given with $(\kappa(s), \tau(s), \mathbf{T}(s), \mathbf{N}(s), \mathbf{B}(s))$ and $(\kappa ^*(s), \tau ^*(s), \mathbf{T}^*(s), \mathbf{N}^*(s), \mathbf{B}^*(s))$.
If $\kappa^* = \kappa$ and $\tau^* = \tau$, then $\beta^* = \beta$ (up to translation(평행이동) and rotation(회전이동)).

___

**PROOF**)
After translation, assume that $\beta(s_0) = \beta^* (s_0)$.
After rotation, further assume that $$\begin{align}
\mathbf{T}(s_0) &= \mathbf{T}^*(s_0)\\
\mathbf{N}(s_0) &= \mathbf{N}^*(s_0)\\
\mathbf{B}(s_0) &= \mathbf{B}^*(s_0)
\end{align}$$
Consider $\mathbf{T}(s)$ and $\mathbf{T}^*(s)$.
$$\begin{align}\frac{\mathrm{d}}{\mathrm{d}s}{<}\mathbf{T}, \mathbf{T}^*{>} &= {<}\mathbf{T}', \mathbf{T}^*{>} + {<}\mathbf{T}, \mathbf{T}^{*}{'}{>} \\
\xrightarrow{\textrm{F-S Formula}}
&= {<}\kappa\mathbf{N}, \mathbf{T}^*{>} + {<}\mathbf{T}, \kappa^*\mathbf{N}^*{>} \\
\xrightarrow{\kappa = \kappa^*}
&= \kappa({<}\mathbf{N}, \mathbf{T}^*{>} + {<}\mathbf{T}, \mathbf{N}^*{>})
\end{align}$$

Consider $\mathbf{N}(s)$ and $\mathbf{N}^*(s)$.
$$\begin{align}
\frac{\mathrm{d}}{\mathrm{d}s}{<}\mathbf{N}, \mathbf{N}^*{>} &= {<}\mathbf{N}', \mathbf{N}^*{>} + {<}\mathbf{N}, \mathbf{N}^{*}{'}{>} \\ 
\xrightarrow{\textrm{F-S Formula}}
&= {<}-\kappa\mathbf{T} + \tau\mathbf{B}, \mathbf{N}^*{>} + {<}\mathbf{N}, -\kappa^*\mathbf{T}^* + \tau^*\mathbf{B}^*{>} \\
\xrightarrow{\kappa^* = \kappa, \tau^* = \tau}
&= -\kappa{<}\mathbf{T}, \mathbf{N}^*{>} + \tau{<}\mathbf{B}, \mathbf{N}^*{>} - \kappa{<}\mathbf{N}, \mathbf{T}^*{>} + \tau{<}\mathbf{N}, \mathbf{B}^*{>}\\
&= -\kappa({<}\mathbf{N}, \mathbf{T}^*{>} + {<}\mathbf{T}, \mathbf{N}^*{>}) + \tau({<}\mathbf{B}, \mathbf{N}^*{>} + {<}\mathbf{N}, \mathbf{B}^*{>})
\end{align}$$
Consider $\mathbf{B}(s)$ and $\mathbf{B}^*(s)$.
$$\begin{align}\frac{\mathrm{d}}{\mathrm{d}s}{<}\mathbf{B}, \mathbf{B}^*{>} &= {<}\mathbf{B}', \mathbf{B}^*{>} + {<}\mathbf{B}, \mathbf{B}^{*}{'}{>} \\
\xrightarrow{\textrm{F-S Formula}}
&= {<}-\tau\mathbf{N}, \mathbf{B}^*{>} + {<}\mathbf{B}, -\tau^*\mathbf{N}^*{>} \\
\xrightarrow{\tau^* = \tau}
&= -\tau({<}\mathbf{N}, \mathbf{B}^*{>} + {<}\mathbf{B}, \mathbf{N}^*{>})\end{align}$$
Therefore, $$\Rightarrow \frac{\mathrm{d}}{\mathrm{d}s}\left({<}\mathbf{T}, \mathbf{T}^*{>} + {<}\mathbf{N}, \mathbf{N}^*{>} + {<}\mathbf{B}, \mathbf{B}^*{>}\right) = 0$$
Let ${<}\mathbf{T}, \mathbf{T}^*{>} + {<}\mathbf{N}, \mathbf{N}^*{>} + {<}\mathbf{B}, \mathbf{B}^*{>} = f(s)$. Note that $f(s)$ is *not* a vector function.
Then, $$\frac{\mathrm{d}}{\mathrm{d}s}f(s) = 0 \rightarrow f(s) = c (\textrm{constant})$$
Consider $f(s_0)$.
Then, $$\begin{align}
{<}\mathbf{T}(s_0), \mathbf{T}^*(s_0){>} + {<}\mathbf{N}(s_0), \mathbf{N}^*(s_0){>} + {<}\mathbf{B}(s_0), \mathbf{B}^*(s_0){>} \\
\xrightarrow{\mathbf{T}(s_0) = \mathbf{T}^*(s_0), \mathbf{N}(s_0) = \mathbf{N}^*(s_0), \mathbf{B}(s_0) = \mathbf{B}^*(s_0)}
\cancelto{1}{||\mathbf{T}(s_0)||} + \cancelto{1}{||\mathbf{N}(s_0)||} + \cancelto{1}{||\mathbf{B}(s_0)||} = 3 = c\\
\end{align}$$
Hence,
$$f(s) = {<}\mathbf{T}(s), \mathbf{T}^*(s){>} + {<}\mathbf{N}(s), \mathbf{N}^*(s){>} + {<}\mathbf{B}(s), \mathbf{B}^*(s){>} = 3$$
Note that ${<}\mathbf{T}(s), \mathbf{T}^*(s){>} =$ $||\mathbf{T}(s)|| \cdot ||\mathbf{T}^{*}(s)|| \cos \theta \leq$ $\cancelto{1}{||\mathbf{T}(s)||} \cdot \cancelto{1}{||\mathbf{T}^{*}(s)||} = 1$.

So, $$f(s) = {<}\mathbf{T}(s), \mathbf{T}^*(s){>}^{\leq 1} + {<}\mathbf{N}(s), \mathbf{N}^*(s){>}^{\leq 1} + {<}\mathbf{B}(s), \mathbf{B}^*(s){>}^{\leq 1} = 3$$So, ${<}\mathbf{T}(s), \mathbf{T}^*(s){>}$ must be $1$.
It means, $\theta$ between $\mathbf{T}$ and $\mathbf{T}^*$ is $0$.
Therefore,
$$\begin{align}\mathbf{T}(s) = \mathbf{T}^{*}(s) &\rightarrow \beta'(s) = \beta^{*}{'}(s) \\
&\xrightarrow{\int}\beta(s) = \beta^{*}(s) (\because \beta(s_0) = \beta^{*}(s_0)) _\blacksquare
\end{align}$$

___

We call this **natural (intrinsic) equation** of a curve.
This means a system of equations $$\begin{cases}
\kappa(s) = \phi(s) \\
\tau(s) = \psi(s)
\end{cases}$$
is given, then the curve $\beta(s)$ is uniquely determined by these two equation as curvature and torsion.

___

Note that $\beta(s)$ is a **unit** speed curve.
We want to compute $\kappa$ and $\tau$, when the curve is **not necessarily unit speed**.
In other words, if the curve $\alpha(t)$ is given, we want to compute $\kappa(t)$ & $\tau(t)$.($\alpha(t)$ is not necessarily unit speed)
Recall the figure below.
![[Pasted image 20240401140714.png|center|400]]
We compute $\kappa(s)$ and $\tau(s)$ from $\beta(s) = \alpha(t(s))$ where $t(s)$ is inverse function of arc length function $s(t)$.
What if we consider $\alpha(t)$ as $\beta(s(t))$?
![[Pasted image 20240401141113.png|center|400]]
We want to compute $\kappa(t)$ and $\tau(t)$ using this idea.

___

$$\begin{align}\alpha'(t) &=\frac{\mathrm{d}}{\mathrm{d}t}\alpha(t) = \frac{\mathrm{d}\beta}{\mathrm{d}s}\frac{\mathrm{d}s}{\mathrm{d}t}\\
\xrightarrow{\because \mathbf{T}(s) = \beta'(s),s=\int_{t_0}^{t}||\alpha'(t)||\mathrm{d}t}
&=\mathbf{T}(s(t))||\alpha'(t)|| \\
\xrightarrow{\textrm{for convenience}}
&=\mathbf{T}||\alpha'||\end{align}$$
So, $$\mathbf{T}(s(t)) = \frac{\alpha'(t)}{||\alpha'(t)||}$$
$$\begin{align}\alpha'(t) &= \mathbf{T}(s(t))||\alpha'(t)||\\ \xrightarrow{\frac{\mathrm{d}}{\mathrm{d}t}}\alpha''(t) &= \frac{\mathrm{d}\mathbf{T}}{\mathrm{d}t}||\alpha'(t)|| + \mathbf{T}(s(t))\frac{\mathrm{d}}{\mathrm{d}t}||\alpha'(t)||\\
\xrightarrow{\textrm{let }||\alpha'(t)|| = Q(t)}
&= \left( \frac{\mathrm{d}\mathbf{T}}{\mathrm{d}s}\frac{\mathrm{d}s}{\mathrm{d}t} \right)Q(t) + \mathbf{T}(s(t))Q'(t)\\ \xrightarrow{\frac{\mathrm{d}s}{\mathrm{d}t}= ||\alpha'(t)|| = Q(t)}
&= \left( \frac{\mathrm{d}\mathbf{T}}{\mathrm{d}s} \right) Q^2(t) + \mathbf{T}(s(t))Q'(t)\\
\xrightarrow{\textrm{by F-S Formula}}
&= \kappa(s(t))\mathbf{N}(s(t))Q^2(t) + \mathbf{T}(s(t))Q'(t)\\ \xrightarrow{\textrm{for convenience}}
&= \kappa Q^2 \mathbf{N}+Q'\mathbf{T}
\end{align}$$
Since we define $Q(t) = ||\alpha'(t)||$, $\alpha'(t) = Q\mathbf{T}$.

Compute $\alpha'(t) \times \alpha''(t)$ to take out $\kappa(s(t))$.

$$\begin{align}
\alpha' \times \alpha'' &= (Q\mathbf{T}) \times (\kappa Q^2 \mathbf{N} + Q'\mathbf{T}) \\
\xrightarrow{\textrm{Note that }\times \textrm{ is distributable}}
&= \kappa Q^3 (\mathbf{T}\times\mathbf{N}) + QQ'(\mathbf{T}\times\mathbf{T})\\
&= \kappa Q^3 \mathbf{B} \\
\xrightarrow {\textrm{take absolute function on both side}} ||\alpha'\times \alpha''|| &= ||\kappa Q^3 \mathbf{B}||\\
\xrightarrow {\textrm{since }\mathbf{B} \textrm{ is unit vector}}
 &= \kappa ||\alpha'||^3\end{align}$$
 Therefore, $$\kappa(t) = \frac{||\alpha'(t) \times \alpha''(t)||}{||\alpha'(t)||^3}$$

**EXAMPLE 1**) Let $\alpha(t) = (t, t^2, t^3)$ (twisted cubic curve)

Suppose we want to reparametrize $\alpha(t)$ using arc length function so that compute $\kappa(s)$.
Then, $$\begin{align}
s &= \int_{0}^{t} ||\alpha'(u)||\mathrm{d}u\\
&= \int_{0}^{t} \sqrt{1+2u^2+3u^3}\mathrm{d}u
\end{align}$$
It is so hard to compute this integral.

Let's use $$\kappa(t) = \frac{||\alpha'(t) \times \alpha''(t)||}{||\alpha'(t)||^3}$$
$$\begin{align}
\alpha'(t) &= (1, 2t, 3t^2)\\
\alpha''(t) &= (0, 2, 6t)\\
\alpha'\times\alpha'' &= (6t^2, -6t, 2)
\end{align}$$
So, $$\kappa(t)
= \frac{||\alpha' \times \alpha''||}{||\alpha'||^3}
= \frac{\sqrt{36t^4 + 36t^2 + 4}}{(1+4t^2+9t^4)^\frac{3}{2}}$$
We can observe that if $t \rightarrow \infty$, then $\kappa(t) \rightarrow 0$.

___

Then, what is $\tau(t)$?

Recall that $$\begin{align}
\alpha' \times \alpha'' &= \textcolor{red}{\kappa Q^3\mathbf{B}}\\
\alpha'' &= Q'\mathbf{T} + \kappa Q^2 \mathbf{N}
\end{align}$$
Compute $\alpha'''(t)$.

$$\alpha'''(t) = Q''\mathbf{T} + Q'\frac{\mathrm{d}\mathbf{T}}{\mathrm{d}t} + \kappa'Q^2\mathbf{N} + 2\kappa QQ'\mathbf{N} + \kappa Q^2\frac{\mathrm{d}\mathbf{N}}{\mathrm{d}t}$$
Note that
$$\begin{align}
\frac{\mathrm{d}\mathbf{T}}{\mathrm{d}t} &= \frac{\mathrm{d}\mathbf{T}}{\mathrm{d}s} \frac{\mathrm{d}s}{\mathrm{d}t} = \mathbf{T}'(s)Q(t) = \kappa(s(t))\mathbf{N}(s(t))Q(t) \\
\frac{\mathrm{d}\mathbf{N}}{\mathrm{d}t} &= \frac{\mathrm{d}\mathbf{N}}{\mathrm{d}s} \frac{\mathrm{d}s}{\mathrm{d}t} = \mathbf{N}'(s)Q(t) = (-\kappa(s(t))\mathbf{T}(s(t))+\tau(s(t))\mathbf{B}(s(t)))Q(t)
\end{align}$$
Therefore,
$$\begin{align}
\alpha'''(t) &= Q''\mathbf{T} + \kappa QQ'\mathbf{N} + \kappa'Q^2\mathbf{N} + 2\kappa QQ'\mathbf{N} + \kappa Q^3(-\kappa\mathbf{T}+\tau\mathbf{B})\\
&= (Q'' - \kappa^2Q^3)\mathbf{T} + (\kappa'Q^2 + 3\kappa QQ')\mathbf{N} + \textcolor{red}{(\kappa\tau Q^3)\mathbf{B}}
\end{align}$$
We want to compute inner product of $\alpha'''$ and $\alpha' \times \alpha''$ so that cancel out $\mathbf{T}$ and $\mathbf{N}$.
$$\begin{align}
{<}\alpha' \times \alpha'', \alpha'''{>} &= \kappa^2\tau Q^6\\
\xrightarrow{\kappa(t) = \frac{||\alpha'(t) \times \alpha''(t)||}{||\alpha'(t)||^3}, ||\alpha'(t)|| = Q} &= ||\alpha'\times \alpha''||^2\tau\\
\rightarrow \tau &= \frac{{<}\alpha' \times \alpha'', \alpha'''{>}}{||\alpha'\times \alpha''||^2}
\end{align}$$

**EXAMPLE 2**) Let $\alpha(t) = (a \cosh \frac{t}{a}, t, 0)$.

If we reparametrize using arc length function, we have to do this.

$$\begin{align}
s &= \int_{0}^{t}||\alpha'(u)||\mathrm{d}u\\
&= \int_{0}^{t}\sqrt{\left(\sinh \left(\frac{u}{a}\right)\right)^2 + 1}\mathrm{d}u \\
&= \int_{0}^{t}\cosh \left(\frac{u}{a}\right)\mathrm{d}u \\ 
&= a\sinh \left(\frac{t}{a}\right)\\
\end{align}$$
We can compute $s^{-1}$, but it is little bit complex.

So, we want to use $$\kappa(t) = \frac{||\alpha'(t) \times \alpha''(t)||}{||\alpha'(t)||^3}$$
$$\begin{align}
\alpha'(t) &= \left(\sinh \left(\frac{t}{a}\right), 1, 0\right) \\
\alpha''(t) &= \left(\frac{1}{a}\cosh \left(\frac{t}{a}\right), 0, 0\right) \\
||\alpha'(t) \times \alpha''(t)|| &= \frac{1}{a}\cosh\left(\frac{t}{a}\right) \\
||\alpha'(t)||^3 &= \left( \sinh^2\left(\frac{t}{a}\right) + 1\right)^{\frac{3}{2}} = \left(\cosh\left(\frac{t}{a}\right)\right)^3
\end{align}$$
$$\kappa(t) = \frac{1}{a\cosh^2\left(\frac{t}{a}\right)}$$
$$\tau(t) = 0(\because \alpha(t)\textrm{ is plane curve})$$
