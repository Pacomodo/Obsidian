1) 컬럼 별칭 주기
```sql
SELECT employee_id, first_name, last_name,
hire_date AS 입사일자,
salary 급여,
commission_pct 수당률,
department_id "부서 번호"
FROM employees;
```

2) 결합 연산자 ||
```sql
SELECT employee_id, first_name, last_name,
first_name || '-' || last_name "성명"
FROM employees;
```

3) 중복 제거

- 예를 들어, 사원의 사번, 부서 번호를 출력하는 문제.
```sql
SELECT employee_id, department_id
FROM employees;
```
- 사원의 부서번호를 출력하시오
```sql
SELECT department_id
FROM employees;
```
- 사원의 부서번호를 중복 없이 출력하시오
```sql
SELECT DISTINCT department_id
FROM employees;
```

4) NULL 주의!
```sql
SELECT employee_id, salary, commission_pct,
salary + (salary*commission_pct) "실급여"
FROM employees;
```

```sql
SELECT employee_id, salary, commission_pct,
salary + (salary*NVL(commission_pct, 0)) "실급여"
FROM employees;
```

5) SELECT ~ FROM ~ WHERE 조건절;
```sql
SELECT *
FROM employees
WHERE salary > 20000;
```

- 비교 연산자 : `>, >=, <, <=, =, <>`
- AND연산자
사원의 사번, 급여를 출력하시오. 단 급여가 15000이상이거나 20000이하인 사원들만 출력합니다.
```sql
SELECT employee_id, salary
FROM employees
WHERE salary >= 15000 AND salary <= 20000;
```
- OR연산자
사원의 사번, 부서번호를 출력하시오. 부서번호가 50, 80인 사원들만 출력합니다.
```sql
SELECT employee_id, department_id
FROM employees
WHERE department_id = 50 OR department_id = 80;
```
- NOT연산자
```sql
SELECT employee_id, salary
FROM employees
WHERE NOT(salary >= 15000 AND salary <= 20000);
```
- BETWEEN 연산자
```sql
SELECT employee_id, salary
FROM employees
WHERE salary BETWEEN 15000 AND 20000;
```
- IN 연산자
사원의 사번, 부서번호를 출력하시오. 부서번호가 50, 80인 사원들만 출력합니다.
```sql
SELECT employee_id, department_id
FROM employees
WHERE department_id IN (50, 80);
```

사원의 사번, 부서번호, 급여를 출력하시오.
부서번호는 50이거나 80이고, 급여는 10000이상 15000이하인 사원들만 출력합니다.
```sql
SELECT employee_id, department_id, salary
FROM employees
WHERE (department_id = 50 OR department_id = 80) AND (salary >= 10000 AND salary <= 15000);
```

```sql
SELECT employee_id, department_id, salary
FROM employees
WHERE (department_id IN (50, 80)) AND (salary BETWEEN 10000 AND 15000);
```

- LIKE 연산자
% 패턴과 \_패턴이 있음.
% : 0개 이상
\_ : 1개

사원의 이름에 'e'를 포함한 사원의 사번, 이름을 출력하시오.
```sql
SELECT employee_id, first_name
FROM employees
WHERE first_name LIKE '%e%';
```

직무 명이 'Manager'로 끝나는 직무들을 출력하시오.
```sql
SELECT *
FROM jobs
WHERE job_title LIKE '%Manager';
```

직무 아이디가 'A'로 시작하고 7글자로 구성된 직무들을 출력하시오.
```sql
SELECT *
FROM jobs
WHERE job_id LIKE 'A______';
```

- NULL 관련 연산자

수당을 받지 않는 사원(commission_pct이 null)들을 출력하시오
```sql
SELECT *
FROM employees
WHERE commission_pct = null;
```
위의 쿼리는 잘못된 쿼리...

```sql
SELECT *
FROM employees
WHERE commission_pct IS NULL;
```

부서배치를 받지 못한 사원들을 출력하시오.
```sql
SELECT *
FROM employees
WHERE department_id IS NULL;
```

관리자가 없는 사원들을 출력하시오.
```sql
SELECT *
FROM employees
WHERE manager_id IS NULL;
```
