aliases:
  - 덧셈군
---

집합 $A \neq \varnothing$ 위에 덧셈 $+$가 정의되어 있고 임의의 원소 $a, b, c \in A$에 대해 다음이 성립할 때, $(A, +)$를 **덧셈군** 이라고 한다.

> 1) $(a + b) + c = a + (b + c)$ (결합 법칙)
> 2) $a + b = b + a$ (교환 법칙)
> 3) 특정한 원소 $0\in A$가 존재하여, 모든 원소 $a \in A$에 대해 등식 $a + 0 = 0 + a = a$가 성립한다.
> 4) 각 $a \in A$에 대하여 $a + b = b + a = 0$인 $b\in G$가 존재한다.

$0$을 $A$의 **영** 또는 **영원(zero element)** 라고 한다.
$b$를 $-a$로 나타내고, $a$의 덧셈에 관한 **역원** 이라고 한다.
덧셈군 $A$에서의 뺄셈 $a-b = a+(-b)$로 정의한다.
