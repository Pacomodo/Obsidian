# 프로젝트명

레시피 공유 웹사이트 개발
# 프로젝트 개요

레시피 공유 웹사이트를 통해 사용자가 다양한 요리법을 작성하고, 공유하고, 검색할 수 있도록 한다.

# 프로젝트 목표

1. **레시피 저장 및 관리**: 사용자가 레시피를 입력하고 저장 및 수정하는 기능.
2. **검색 및 필터링**: 재료, 카테고리, 조리 시간 등을 기준으로 레시피를 검색.
3. **사용자 리뷰 및 평점**: 사용자가 다른 사람의 레시피에 대해 리뷰를 작성하고 평점을 매길 수 있는 기능.
4. **즐겨찾기**: 사용자가 자주 사용하는 레시피를 즐겨찾기에 추가할 수 있는 기능.
5. **다른 사용자 구독**: 다른 사용자를 구독해서 다른 사람의 레시피를 우선으로 볼 수 있는 기능

# 사용자 관리 기능 명세서

#### 1. 기능 설명
사용자 관리 기능은 회원 가입, 로그인, 로그아웃, 프로필 관리, 비밀번호 찾기, 계정 삭제, 그리고 다른 사용자 구독 기능을 포함한다.
#### 2. 기능 요구사항
##### 2.1 회원 가입
- **기능 설명:** 사용자가 새로운 계정을 생성한다.
- **입력:**
  - 사용자명 (username)
  - 비밀번호 (password)
  - 이메일 주소 (email)
  - 프로필 사진 (선택 사항)
- **처리:**
  - 사용자명과 이메일의 중복 확인
  - 비밀번호 유효성 검사 (최소 8자, 특수 문자 포함)
- **출력:**
  - 가입 성공 메시지
  - 가입 실패 시 오류 메시지 (예: 중복된 사용자명 또는 이메일)
##### 2.2 로그인
- **기능 설명:** 기존 사용자가 계정에 로그인한다.
- **입력:**
  - 사용자명 또는 이메일
  - 비밀번호
- **처리:**
  - 사용자명 또는 이메일과 비밀번호 일치 확인
- **출력:**
  - 로그인 성공 시 사용자 대시보드로 이동
  - 로그인 실패 시 오류 메시지 (예: 잘못된 사용자명/이메일 또는 비밀번호)
##### 2.3 로그아웃
- **기능 설명:** 사용자가 계정에서 로그아웃한다.
- **처리:**
  - 세션 종료
- **출력:**
  - 로그아웃 후 홈페이지로 이동
##### 2.4 사용자 프로필 관리
- **기능 설명:** 사용자가 자신의 프로필 정보를 수정한다.
- **입력:**
  - 사용자명 (수정 가능)
  - 이메일 (수정 가능)
  - 비밀번호 변경 (선택 사항)
  - 프로필 사진 업로드 (선택 사항)
- **처리:**
  - 변경된 사용자명과 이메일의 중복 확인
  - 비밀번호 유효성 검사
- **출력:**
  - 수정 성공 메시지
  - 수정 실패 시 오류 메시지 (예: 중복된 사용자명 또는 이메일)
##### 2.5 비밀번호 찾기
- **기능 설명:** 사용자가 비밀번호를 재설정한다.
- **입력:**
  - 이메일 주소
- **처리:**
  - 이메일 주소 유효성 확인
  - 비밀번호 재설정 링크 이메일 전송
- **출력:**
  - 이메일 전송 성공 메시지
  - 실패 시 오류 메시지 (예: 등록되지 않은 이메일 주소)
##### 2.6 계정 삭제
- **기능 설명:** 사용자가 자신의 계정을 삭제한다.
- **입력:**
  - 사용자 확인 (비밀번호 재입력)
- **처리:**
  - 비밀번호 일치 확인
  - 계정 및 관련 데이터 삭제
- **출력:**
  - 계정 삭제 성공 메시지
  - 실패 시 오류 메시지 (예: 비밀번호 불일치)
##### 2.7 구독 관리
- **기능 설명:** 사용자가 다른 사용자를 구독하여 그 사용자의 레시피를 우선적으로 볼 수 있도록 한다.
- **하부 기능들:**
  - 사용자 구독
  - 구독 목록 보기
  - 구독 취소
##### 2.8 사용자 검색
- **기능 설명:** 사용자가 다른 사용자를 검색할 수 있도록 한다.
#### 3. 그 외 요구사항
- 모든 비밀번호는 해시 처리되어 저장되어야 한다.
- 모든 입력 필드는 유효성 검사를 통해 부적절한 데이터 입력을 방지해야 한다.
- 관리자는 예외로 모든 사용자의 정보를 수정할 수 있음.
- 사용자 검색 결과는 페이지 별로 효율적으로 나타나게 표시한다.
#### 4. 제약 조건
- 데이터베이스는 중복된 사용자명과 이메일을 허용하지 않음.

# 레시피 관리 기능 명세서

#### 1. 기능 설명
레시피 관리 기능은 레시피 추가, 수정, 삭제, 보기 기능을 포함한다. 사용자는 자신의 레시피를 관리하고, 다른 사용자의 레시피를 열람할 수 있다.
#### 2. 기능 요구사항
##### 2.1 레시피 추가
- **기능 설명:** 사용자가 새로운 레시피를 추가
- **입력:**
  - 레시피 이름 (필수)
  - 설명 (선택)
  - 재료 목록 (필수)
  - 조리법 (필수)
  - 조리 시간 (필수)
  - 카테고리 (필수)
  - 사진 (선택)
- **처리:**
  - 필수 입력 항목 확인
  - 레시피 데이터 저장
- **출력:**
  - 추가 성공 메시지
  - 추가 실패 시 오류 메시지 (예: 필수 항목 누락)
##### 2.2 레시피 수정
- **기능 설명:** 사용자가 기존의 레시피를 수정
- **입력:**
  - 수정할 레시피 선택
  - 레시피 이름 (수정 가능)
  - 설명 (수정 가능)
  - 재료 목록 (수정 가능)
  - 조리법 (수정 가능)
  - 조리 시간 (수정 가능)
  - 카테고리 (수정 가능)
  - 사진 (수정 가능)
- **처리:**
  - 수정 권한 확인 (작성자만 수정 가능)
  - 수정된 레시피 데이터 저장
- **출력:**
  - 수정 성공 메시지
  - 수정 실패 시 오류 메시지 (예: 권한 없음, 필수 항목 누락)
##### 2.3 레시피 삭제
- **기능 설명:** 사용자가 기존의 레시피를 삭제
- **입력:**
  - 삭제할 레시피 선택
- **처리:**
  - 삭제 권한 확인 (작성자만 삭제 가능)
  - 레시피 데이터 삭제
- **출력:**
  - 삭제 성공 메시지
  - 삭제 실패 시 오류 메시지 (예: 권한 없음)
##### 2.4 레시피 보기
- **기능 설명:** 사용자가 레시피의 세부 정보를 열람
- **입력:**
  - 열람할 레시피 선택
- **출력:**
  - 레시피 상세 정보 (이름, 설명, 재료, 조리법, 조리 시간, 카테고리, 사진, 작성자 정보)
  - 리뷰 보기
  - 평점 보기
  - 구독한 사용자 레시피 우선 보기 (사용자가 구독한 사용자의 레시피가 우선적으로 표시)
##### 2.5 레시피 검색
* **기능 설명:** 사용자가 레시피를 검색
* **하부 기능들:**
  * 재료별 검색
  * 카테고리별 검색
  * 조리 시간별 검색
  * 평점별 필터링
#### 3. 그 외 요구사항
- 레시피 추가, 수정, 삭제 기능은 레시피를 작성한 사용자만 접근 가능해야 함.
- 모든 입력 필드는 유효성 검사를 통해 부적절한 데이터 입력을 방지해야 함.
- 관리자는 예외로 모든 레시피를 수정할 수 있음.
- 검색 결과는 페이지별로 효율적으로 표시

# 리뷰 및 평점 기능 명세서

#### 1. 기능 설명
리뷰 및 평점 기능은 리뷰 작성, 수정, 삭제, 평점 매기기, 수정, 삭제 기능을 포함한다. 사용자는 자신의 리뷰을 공유하고 다른 사용자의 의견을 볼 수 있다.
#### 2. 기능 요구사항
##### 2.1 리뷰/평점 작성
- **기능 설명:** 사용자가 레시피에 대한 리뷰를 작성
- **입력:**
  - 리뷰 내용 (텍스트, 필수)
  - 평점 (1~5 사이의 정수, 필수)
- **처리:**
  - 리뷰 내용과 평점 유효성 검사
  - 리뷰 데이터 저장
- **출력:**
  - 리뷰 작성 성공 메시지
  - 작성된 리뷰 표시
  - 리뷰 작성 실패 시 오류 메시지 (예: 유효성 검사 실패)
##### 2.2 리뷰/평점 수정
- **기능 설명:** 사용자가 자신의 리뷰를 수정
- **입력:**
  - 수정할 리뷰 선택
  - 수정된 리뷰 내용 (텍스트, 필수)
  - 수정된 평점 (0~5 사이의 정수, 필수)
- **처리:**
  - 리뷰 작성자 확인 (작성자 본인만 수정 가능)
  - 수정된 리뷰 내용과 평점 유효성 검사
  - 수정된 리뷰 데이터 저장
- **출력:**
  - 리뷰 수정 성공 메시지
  - 수정된 리뷰 표시
  - 리뷰 수정 실패 시 오류 메시지 (예: 권한 없음, 유효성 검사 실패)
##### 2.3 리뷰/평점 삭제
- **기능 설명:** 사용자가 자신의 리뷰를 삭제
- **입력:**
  - 삭제할 리뷰 선택
- **처리:**
  - 리뷰 작성자 확인 (작성자 본인만 삭제 가능)
  - 리뷰 데이터 삭제
- **출력:**
  - 리뷰 삭제 성공 메시지
  - 리뷰 삭제 실패 시 오류 메시지 (예: 권한 없음)
#### 3. 그 외 요구사항
- 리뷰 및 평점 작성, 수정, 삭제 기능은 본인만 접근 가능해야 함.
- 모든 입력 필드는 유효성 검사를 통해 부적절한 데이터 입력을 방지해야 함.
- 관리자는 예외로 모든 리뷰 및 평점을 수정할 수 있음.
#### 4. 제약 조건
- 하나의 레시피에 대해 하나의 사용자만 한 번 리뷰 및 평점을 남길 수 있어야 함.

# 즐겨찾기 기능 명세서

#### 1. 기능 설명
즐겨찾기 기능은 레시피 즐겨찾기 추가, 즐겨찾기 목록 보기, 즐겨찾기에서 제거 기능을 포함한다. 사용자는 즐겨찾기를 통해 자신이 좋아하는 레시피를 쉽게 접근하고 관리할 수 있다.
#### 2. 기능 요구사항
##### 2.1 레시피 즐겨찾기 추가
- **기능 설명:** 사용자가 특정 레시피를 즐겨찾기에 추가
- **입력:**
  - 즐겨찾기에 추가할 레시피 선택
- **처리:**
  - 레시피 ID와 사용자 ID를 이용해 즐겨찾기 목록에 추가
  - 중복된 레시피는 추가되지 않도록 처리
- **출력:**
  - 즐겨찾기 추가 성공 메시지
  - 즐겨찾기 추가 실패 시 오류 메시지 (예: 이미 추가된 레시피)
##### 2.2 즐겨찾기 목록 보기
- **기능 설명:** 사용자가 즐겨찾기에 추가한 레시피 목록을 볼 수 있음
- **입력:**
  - 사용자 ID (로그인된 사용자)
- **처리:**
  - 사용자 ID를 이용해 즐겨찾기 목록 조회
- **출력:**
  - 즐겨찾기 레시피 목록 (레시피 이름, 설명, 썸네일 이미지 등)
  - 즐겨찾기 목록이 비어 있을 경우 "즐겨찾기 목록이 비어 있습니다" 메시지
##### 2.3 즐겨찾기에서 제거
- **기능 설명:** 사용자가 즐겨찾기에서 특정 레시피를 제거
- **입력:**
  - 제거할 레시피 선택
- **처리:**
  - 레시피 ID와 사용자 ID를 이용해 즐겨찾기 목록에서 제거
- **출력:**
  - 즐겨찾기 제거 성공 메시지
  - 즐겨찾기 제거 실패 시 오류 메시지 (예: 즐겨찾기에 없는 레시피)
#### 3. 그 외 요구사항
- 즐겨찾기 기능은 인증된 사용자(본인)만 접근 가능해야 한다.
- 모든 입력 필드는 유효성 검사를 통해 부적절한 데이터 입력을 방지해야 한다.
#### 4. 제약 조건
- 한 사용자는 동일한 레시피를 중복해서 즐겨찾기에 추가할 수 없어야 한다.
