1. Windows PowerShell 실행
2. 새 탭에서 실행 우클릭 -> 우분투 실행
3. 우분투 나노를 사용하자.
4. 기존 파일을 열거나 새 파일을 생성하려면 nano와 파일 이름을 차례로 입력합니다.
5. 그러면 새 편집기 창이 열리고 파일 편집을 시작할 수 있습니다. 

창 아래쪽에는 나노 편집기에서 사용할 수 있는 가장 기본적인 명령 바로 가기 목록이 있습니다.

모든 명령 앞에는 ^ 또는 M 문자가 붙습니다. 캐럿 기호(^)는 Ctrl 키를 나타냅니다. 예를 들어 ^J 명령은 Ctrl 키와 J 키를 동시에 누른다는 의미입니다. 문자 M은 Alt 키를 나타냅니다.

Ctrl+g를 입력하여 모든 명령 목록을 볼 수 있습니다. 

파일을 열려면 파일에 대한 읽기 권한이 있어야 합니다.

특정 줄과 문자에 커서가 있는 파일을 열려면 다음 구문을 사용하십시오.

```
nano +line_number,character_number filename
```

문자_숫자를 생략하면 커서가 첫 번째 문자에 배치됩니다.

## 파일을 편집

vi와 달리 nano는 모덜리스 편집기이므로 파일을 연 후 즉시 텍스트를 입력하고 편집할 수 있습니다.

커서를 특정 줄과 문자 번호로 이동하려면 Ctrl+_ 명령을 사용합니다. 화면 하단의 메뉴가 변경됩니다. 줄 번호 입력, 열 번호: 필드에 숫자를 입력하고 Enter를 누릅니다.

## 검색 및 교체 

텍스트를 검색하려면 Ctrl+w를 누르고 검색어를 입력한 다음 Enter 키를 누릅니다. 커서가 첫 번째 일치로 이동합니다. 다음 일치로 이동하려면 Alt+w를 누릅니다. 

검색하고 바꾸려면 Ctrl+\를 누릅니다. 검색어와 바꿀 텍스트를 입력합니다. 편집기가 첫 번째 일치로 이동하여 교체 여부를 묻습니다. Y 또는 N을 누른 후 다음 일치로 이동합니다. A를 누르면 일치 항목이 모두 바뀝니다.

## 커핑, 커팅 및 붙여넣기 작업을 수행

텍스트를 선택하려면 커서를 텍스트 시작 부분으로 이동하고 Alt+a를 누릅니다. 그러면 선택 표시가 설정됩니다. 화살표 키를 사용하여 선택할 텍스트의 끝으로 커서를 이동합니다. 선택한 텍스트가 강조 표시됩니다. 선택을 취소하려면 Ctrl+6을 누릅니다.

Alt+6 명령을 사용하여 선택한 텍스트를 클립보드에 복사합니다. Ctrl+k가 선택한 텍스트를 잘라냅니다.

전체 라인을 자르려면 커서를 선으로 이동하고 Ctrl+k를 누르기만 하면 됩니다. Ctrl+k를 여러 번 눌러 여러 줄을 자를 수 있습니다.

텍스트를 붙여넣으려면 커서를 텍스트를 넣을 위치로 이동하고 Ctrl+u를 누릅니다.

## 저장하고 종료

파일의 변경 내용을 저장하려면 Ctrl+o를 누릅니다. 파일이 존재하지 않는 경우 파일을 저장하면 파일이 생성됩니다. 

나노를 종료하려면 Ctrl+x를 누릅니다. 저장하지 않은 변경 사항이 있는 경우 변경 내용을 저장할 것인지 묻는 메시지가 표시됩니다.

파일을 저장하려면 파일에 대한 쓰기 권한이 있어야 합니다. 새 파일을 생성하는 경우 파일이 생성된 디렉터리에 대한 쓰기 권한이 있어야 합니다.

## 나노(나노르c)를 사용자 정의

나노가 시작되면 시스템 전체 구성 파일 /etc/nanorc와 사용자별 파일 ~.config/nano/nanorc 및 파일이 있는 경우 ~.nanorc에서 구성 파라미터를 읽습니다.

사용자 파일에 지정된 옵션이 글로벌 옵션보다 우선합니다.

사용 가능한 모든 옵션의 전체 목록을 보려면 나노크 페이지를 방문하십시오.

## 구문 강조 표시

Nano는 가장 자주 사용되는 파일 형식에 대한 구문 강조 표시 규칙을 제공합니다. 대부분의 Linux 시스템에서 구문 파일은 /usr/share/nano 디렉토리에 저장되며 기본적으로 /etc/nanorc 구성 파일에 포함됩니다.

```
# /etc/nanorc

include "/usr/share/nano/*.nanorc"
```

새 파일 형식에 대해 강조 표시를 실행하는 가장 쉬운 옵션은 구문 강조 표시 규칙이 포함된 파일을 /usr/share/nano 디렉토리에 복사하는 것입니다.

## Nano를 기본 텍스트 편집기로 설정

대부분의 Linux 시스템에서는 기본적으로 visudo 및 crontab과 같은 명령에 대한 기본 텍스트 편집기가 vi로 설정됩니다. Nano를 기본 텍스트 편집기로 사용하려면 VISUAL 및 EDITOR 환경 변수를 변경해야 합니다.

Bash 사용자는 ~.bashrc 파일에 변수를 내보낼 수 있습니다.

```
# ~/.bashrc

export VISUAL=nano
export EDITOR="$VISUAL"
```
