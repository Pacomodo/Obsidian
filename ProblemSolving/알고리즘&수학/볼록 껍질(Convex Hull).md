### 볼록 껍질이란?

볼록 껍질(Convex Hull)은 2차원 좌표 평면에 놓여 있는 점들이 주어졌을 때, 해당 점들을 모두 포함하는 면적이 가장 작은 볼록 다각형을 의미합니다.
![[Pasted image 20251215131157.png|center|400]]
볼록 껍질을 구하는 것이 이 알고리즘의 목표라고 할 수 있습니다.
### 점과 다각형의 표현

일반적으로 알고리즘 문제에서는 하나의 점을 표현하기 위해 $x$좌표와 $y$좌표 하나의 쌍으로 표현하는 경우가 많습니다.

파이썬의 경우 다음과 같이 클래스를 사용하여 나타낼 수 있습니다.
```python
class Point:
	def __init__(x, y):
		self.x = x;
		self.y = y;
```

C/C++/자바의 경우 문제에서 어떠한 자료형을 사용하는지 확인하여 점의 좌표를 `int`로 표현하든, `double`로 표현하든, 적절히 잘 사용하면 됩니다.

다각형은 일반적으로 점들의 리스트로 주어집니다. 즉, 주어진 점들을 순서대로 이으면 다각형이 완성되는 구조입니다.

다각형은 볼록 다각형과 오목 다각형이 존재합니다.

우리가 구하고자 하는 것은 모든 점을 포함하는 가장 작은 볼록 다각형이므로, 최종적으로 나온 결과물(점들의 리스트)은 볼록 다각형임을 생각합시다.

### 벡터와 CCW

일반적으로 계산기하에서는 벡터를 자주 사용합니다.

일반적으로 벡터를 구현할 때는 시작점이 중요하지 않으므로, 점의 표현방식과 같이 구현한다.

특히 볼록 껍질을 구현하는데에 있어서, 두 벡터 순서대로 시계방향을 이루는지, 반시계 방향을 이루는지를 알아내는 것은 매우 중요합니다.

이를 CCW알고리즘(CounterClockWise)이라고 부르는데, 말이 거창하지만 결국 외적입니다.

![[Pasted image 20251215133655.png|center|600]]

세 점이 다음과 같이 주어질 때, 이 점들이 시계방향을 이루는지 반시계방향을 이루는지, 일직선을 이루는지를 판별하기 위해서는 다음과 같이 벡터를 2개로 생각해야 합니다.

![[Pasted image 20251215133933.png|center|400]]
이 경우 두 벡터 $\vec{a}$와 $\vec{b}$를 외적하면 양수가 나옵니다.
![[Pasted image 20251215134210.png|center|400]]
즉, 세 점이 반시계 방향을 이룬다면 두 벡터를 외적했을 때 양수가 나오고, 세 점이 시계방향을 이룬다면 음수, 세 점이 일직선이면 0이 됩니다.
![[Pasted image 20251215145347.png|center|400]]
즉, $a_{x}b_{y}-a_{y}b_{x}$가 양수라면 반시계, 음수라면 시계를 의미합니니다.

CCW를 구현해볼 수 있는 문제
[https://www.acmicpc.net/problem/11758](https://www.acmicpc.net/problem/11758)
각자 구현해봅시다.

### 1. 그라함 스캔(Graham's Scan)

이제 볼록 껍질을 구현하는 첫번째 방법인 그라함 스캔을 알아봅시다.

그라함 스캔은 다음과 같은 순서대로 진행합니다.

1. $y$좌표가 가장 작은 점 P를 찾는다.
	1. 만약 그러한 점이 여러 개라면, 그 중에서 $x$좌표가 가장 작은 점을 찾는다.
	2. 이 점은 **항상** 볼록 껍질에 포함되있음을 유념하자.
2. 점 P를 기준으로 모든 점들을 $x$축에 대해 각도가 증가하는 순으로 정렬한다.
	1. 이때, atan과 같은 역삼각함수로 직접 각도를 구해서 정렬해도 되며,
	2. 위에서 말한 CCW로 비교 함수를 정의하여, 점들을 반시계 방향으로 정렬해도 된다.
	-  ![[image1.png|200]] ![[image1 1.png|200]]
	- 다만 1번의 경우, 실수 오차가 발생할 수도 있기 때문에 비추천
	- 2번의 경우, CCW값이 음수일때만 두 점을 SWAP하도록 비교함수를 정의하면 된다.
	- CCW값이 0인 경우(일직선)라면 P와의 거리를 측정해서 가까운 거리 순으로 정의하자.
3. 각 점마다 스택 맨 위의 두 점과 현재 점이 어느 방향으로 회전하는지 판정한다.
	- 스택의 크기가 $3$보다 작은 경우 스택에 점을 넣는다.
	- 그렇지 않을 때
		- 반시계 방향을 이룬다면 스택에 점을 넣는다.
		- 시계 방향을 이룬다면 스택 맨 위의 점을 빼고 3번 과정을 다시 반복.
4. 모든 점마다 이 과정을 반복하면 스택에 남겨진 점들이 볼록 껍질이 된다.

파이썬으로 구현된 코드는 다음과 같습니다.

```python
# Geometry Template

# N차원 시점이 P_s, 종점이 P_e인 방향 벡터
def direction_vector(P_s, P_e):
    return tuple(P_e[i]-P_s[i] for i in range(len(P_e)))
    
# 벡터 a와 벡터 b의 외적(2차원)
def cross_product_1(vec_a, vec_b):
    return vec_a[0]*vec_b[1] - vec_a[1]*vec_b[0]

# P1->P2->P3 순으로 이었을 때 시계, 반시계, 일직선 판단(2차원)
def CCW(P1, P2, P3):
    vec_a = direction_vector(P1, P2)
    vec_b = direction_vector(P2, P3)
    K = cross_product_1(vec_a, vec_b)
    if K > 0: return 1
    elif K == 0: return 0
    else: return -1

# 그라함 스캔으로 구현한 컨벡스헐
from math import atan2
def convex_hull_with_graham_scan(point_li):
    pivot = min(point_li, key = lambda point: (point[1], point[0]))
    point_li.remove(pivot)
    point_li.sort(key = lambda point:(atan2(point[1]-pivot[1], point[0]-pivot[0]), distance_square(pivot, point)))
    hull = [pivot]
    for point in point_li:
        while len(hull) > 1:
            if CCW(hull[-2], hull[-1], point) > 0:
                break
            hull.pop()
        hull.append(point)
    return hull
```

위의 코드는 각도 정렬을 atan2함수를 이용하여 구현했으니, CCW를 이용한 각도정렬을 활용하여 구현하시면 좋을 것 같습니다.
### 2. Monotone Chain(Andrew's Algorithm)

- 그라함 스캔보다 구현이 간단한 모노톤 체인 방식을 알아봅시다.
- 그라함 스캔의 동작 방식을 구현하는 것 자체는 그리 어렵진 않습니다.
- 다만, 그라함 스캔 이전에 각도 정렬을 제대로 구현하는 것은 조금 까다롭습니다.
- 위에서는 atan2함수를 사용해서 구현했습니다.
- 테스트케이스가 까다로운 문제의 경우 해당 구현은 실수오차가 나게끔 되어있기 때문에 CCW로 정렬함수를 구현해야합니다.
- 이 과정에서 가까운 점 처리등의 귀찮은 예외처리들이 나옵니다.
- 이 구현 방식은 각도정렬이 필요 없기 때문에 그러한 부분에서 구현이 까다롭지 않습니다.
- 그냥 우리가 잘 아는 사전순 정렬을 하면 됩니다.

- 기본적인 접근 방식은 그라함 스캔과 동일합니다.
- 이 방식은 볼록 껍질에서 윗껍질과 아랫껍질을 따로 따로 구성하여 합친다는 점이 다릅니다.

- 점들이 있으면, 맨 왼쪽의 점($x$좌표가 가장 작고, $y$좌표가 가장 작은 점)은 항상 볼록 껍질의 시작점이 됩니다.
- 이 성질을 이용해 사전순 정렬을 한다면, 첫번째 점이 항상 볼록껍질의 구성점이라는 사실을 알 수 있습니다.

알고리즘은 다음과 같은 순서를 따릅니다.

1. 점들을 사전순 정렬한다.(그냥 정렬임)
2. 첫번째 점과 두번째 점을 스택에 넣는다.
3. 주어진 점들을 순회하며 그라함 스캔 하듯 똑같이 진행하면 아랫껍질이 만들어진다.
4. 마찬가지로, CCW일때 스택에 넣는 것이 아닌, CW일때 스택에 넣도록 하면 윗껍질이 만들어진다.
5. 합친다.
	1. 윗껍질과 아랫껍질을 합칠 때 윗껍질의 순서는 거꾸로 되어있으므로, 뒤집어서 합치면 된다.
	2. 중복된 점(시작점과 끝점)은 겹치므로 두 점을 빼주고 합치자.
