이전에 했던 Surface의 정의를 생각해봅시다.

>[!Recall]
>An surface $S$ is a subset $S$ of $\mathbb{R}^3$, such that for each $\mathbf{p} \in S$, there is an open set $u \in \mathbb{R}^2$ and an open set $W \in \mathbb{R}^3$ containing $\mathbf{p}$ such that $S\cap W$ is homeomorphic to $u$.
>
>![[Pasted image 20240405171133.png|center|400]]
>Here, **homeomorphic** means, there is a continuous bijection $f: u \rightarrow S\cap W$ where $f^{-1}$ is also continuous.

Surface의 정의는 $\mathbb{R}^{2}$에서 $\mathbb{R}^{3}$로 가는 개념이었습니다. 이를 확장시켜, 다음과 같은 개념을 생각해볼 수 있을 것입니다.

> [!Definition]
> More generally (Topological object), a manifold(다양체) **locally looks like** $\mathbb{R}^{n}$.
> ![[SmartSelect_20240415_180242_Samsung Notes.jpg|center|400]]
> $f_{\alpha}:U_{\alpha} \to \mathcal{M}$ is homeomorphism where $U_{\alpha}$ is an open neighborhood for arbitrary point in $\mathbb{R}^{n}$. Hence, $\mathcal{M} = \underset{ \alpha }{ \bigcup }f_{\alpha}(U_{\alpha})$.

이렇게 정의를 할 경우, image가 $\mathcal{M}$위의 임의의 점 $\mathbf{p}$를 포함하도록 하는 $f$가 다양하게 정의될 수 있습니다.
예를 들어, 다음과 같은 그림을 봅시다.
![[SmartSelect_20240415_203036_Samsung Notes.jpg|center|400]]
$\mathbf{p}\in f_{\alpha}(U_{\alpha}), f_{\beta}(U_{\beta})$입니다. 이때, open neighborhood $U_{\alpha}$에서 open neighborhood $U_{\beta}$으로 가는 homeomorphism $g_{\beta \alpha}$를 잡아줄 수 있습니다. 더불어, $g_{\beta \alpha}$의 역함수 $g_{\alpha \beta}$를 생각해봅시다.
이때, 다음과 같은 관계가 성립합니다.
$$
\begin{align}
f_{\beta} \circ g_{\beta \alpha} &= f_{\alpha} \\
f_{\alpha} \circ g_{\alpha \beta} &= f_{\beta} \\
g_{\beta \alpha} &=f^{-1}_{\beta}\circ f_{\alpha} \\
g_{\alpha \beta} &= f^{-1}_{\alpha} \circ f_{\beta}
\end{align}
$$
따라서, 우리가 open neighborhood를 어떻게 잡든지 간에 우리가 다루기 쉬운 neighborhood로 보내어서 생각할 수 있습니다.
이러한 $f_{\alpha}$하나 하나는 $U_{\alpha}$를 manifold $\mathcal{M}$로 붙이는 역할을 하므로, patch 또는 chart라고 부르며, 이러한 $f_{\alpha}$들을 모은 것을 $\mathcal{M}$의 atlas라고 부릅니다.

우리가 Curve에서 했던 일들을 잘 생각해봅시다.
같은 Curve를 두고서 $t$로 parametrize하던, arc length parametrization을 통해 $s$로 parametrize하던 간에 같은 결과를 얻을 수 있었습니다. 이와 비슷한 맥락이라고 생각할 수 있습니다.

다시 돌아와서, Parametric Surface에 대해서 공부해봅시다.

## Parametric Surface

이전에 했던 내용을 상기시켜봅시다.
![[SmartSelect_20240415_212408_Samsung Notes.jpg|center|400]]
$$
\begin{align}
\boldsymbol{\sigma}:U^{\in \mathbb{R}^{2}} &\to \mathbb{R}^{3} \\
(u,v) &\mapsto (x(u,v), y(u,v), z(u,v))
\end{align}
$$
어떤 Surface patch $\boldsymbol{\sigma}$가 **smooth** and **regular**할 조건은 다음과 같았습니다.

> [!Recall]
> $\boldsymbol{\sigma}$ has partial derivatives $\frac{ \partial^{k} \boldsymbol{\sigma} }{ \partial w_{1} \partial w_{2}\dots \partial w_{k} }$($w_{i} = u \text{ or }v$) of **all** order and continuous for all $k \geq 1$
> $\iff x(u,v), y(u,v), z(u,v)$ are all smooth.
> Note that $\frac{ \partial \boldsymbol{\sigma} }{ \partial u }=\left( \frac{ \partial x }{ \partial u }, \frac{ \partial y }{ \partial u },\frac{ \partial z }{ \partial u } \right), \frac{ \partial \boldsymbol{\sigma} }{ \partial v }=\left( \frac{ \partial x }{ \partial v }, \frac{ \partial y }{ \partial v },\frac{ \partial z }{ \partial v } \right)$.

> [!Recall]
>$\alpha(t)$ is regular if $\lVert \alpha'(t) \rVert\neq 0$ for any $t$.
>$$\Rightarrow \mathbf{T}(t) = \frac{\alpha'(t)}{\lVert \alpha'(t) \rVert }$$ Similarly, $\boldsymbol{\sigma}$ is **regular** if at any $(u_{0},v_{0}) \in U$, $\frac{ \partial \boldsymbol{\sigma} }{ \partial u }(u_{0},v_{0}), \frac{ \partial \boldsymbol{\sigma} }{ \partial v }(u_{0}, v_{0})$ are linearly independent $\iff \left( \boldsymbol{\sigma}_{u}\times \boldsymbol{\sigma}_{v} \right)_{\text{at}(u_{0},v_{0})} \neq \mathbf{0} \iff \lVert \boldsymbol{\sigma}_{u}\times \boldsymbol{\sigma}_{v} \rVert \neq 0$.
>So that we can define well unit normal vector for tangent plane.

## Examples

다양한 예시들을 통해 Smooth와 Regular조건을 확인해봅시다.
1. $z = f(x,y)$의 예시를 봅시다.
![[SmartSelect_20240416_001751_Samsung Notes.jpg|center|300]]
이 Surface는 다음과 같이 parametrize할 수 있습니다.
$$
\begin{align}
\boldsymbol{\sigma}:U^{\subset \mathbb{R}^{2}} &\to \mathbb{R}^{3} \\
(u,v) &\mapsto (u,v,f(u,v))
\end{align}
$$
편미분을 해봅시다.
$$
\begin{align}
\frac{ \partial \boldsymbol{\sigma} }{ \partial u } &= \left( 1, 0, \frac{ \partial f }{ \partial u }  \right) \\
\frac{ \partial \boldsymbol{\sigma} }{ \partial v } &= \left( 0,1,\frac{ \partial f }{ \partial v }  \right) \\
\boldsymbol{\sigma}_{u} \times \boldsymbol{\sigma}_{v} &= \left( -\frac{ \partial f }{ \partial u } , -\frac{ \partial f }{ \partial v } , 1 \right) \neq \mathbf{0} \\
\end{align}
$$
따라서, $f(u,v)$의 조건이 어떻든 간에, 이 Surface는 Regular함을 보장할 수 있습니다.
$$
\begin{align}
\frac{ \partial \boldsymbol{\sigma} }{ \partial u } &= \left( 1, 0, \frac{ \partial f }{ \partial u }  \right) \\
\frac{ \partial \boldsymbol{\sigma} }{ \partial v } &= \left( 0,1,\frac{ \partial f }{ \partial v }  \right) \\
\frac{ \partial^{2} \boldsymbol{\sigma} }{ \partial u^{2} } &= \left( 0, 0, \frac{ \partial^{2} f }{ \partial u^{2} }  \right) \\
\frac{ \partial^{2} \boldsymbol{\sigma} }{ \partial u \partial v } &= \left( 0,0,\frac{ \partial^{2} f }{ \partial u \partial v }  \right) \\
\frac{ \partial^{2} \boldsymbol{\sigma} }{ \partial v^{2} } &= \left( 0, 0, \frac{ \partial^{2} f }{ \partial v^{2} }  \right) \dots\\
\end{align}
$$
이 이후의 partial derivatives는 모두 $f$와만 관련이 있습니다. 즉, $f$가 smooth하다면 $\boldsymbol{\sigma}$또한 smooth 함을 확인할 수 있습니다.

2. Cylinder(주(柱)면)의 예시를 봅시다.
어떤 plane curve $\alpha(t)$가 다음과 같이 주어져있다고 합시다.
![[SmartSelect_20240416_005000_Samsung Notes.jpg|center|300]]
$$
\alpha(t) = (x(t), y(t))
$$
이 plane curve $\alpha(t)$를 $z$축으로 세워 만든 Cylinder를 생각해봅시다.
![[SmartSelect_20240416_005711_Samsung Notes.jpg|center|300]]
이 Cylinder는 다음과 같이 parametrize할 수 있습니다.
$$
\boldsymbol{\sigma}: (u,v) \mapsto (x(u), y(u), v)
$$
편미분을 해봅시다.
$$
\begin{align}
\frac{ \partial \boldsymbol{\sigma} }{ \partial u } &= (x',y',0) \\
\frac{ \partial \boldsymbol{\sigma} }{ \partial v } &= (0, 0, 1) \\
\boldsymbol{\sigma}_{u}\times \boldsymbol{\sigma}_{v} &= (y',-x',0) \\
\lVert \boldsymbol{\sigma}_{u}\times \boldsymbol{\sigma}_{v} \rVert &= \sqrt{ x'^{2} + y'^{2} } = \lVert \alpha(t) \rVert 
\end{align}
$$
따라서, $\lVert \alpha(t) \rVert \neq 0$이라면, 즉, $\alpha(t)$가 Regular하다면, $\boldsymbol{\sigma}$또한 Regular함을 확인할 수 있습니다.
$$
\begin{align}
\frac{ \partial^{2} \boldsymbol{\sigma} }{ \partial u \partial v } &= (0, 0, 0) \\
\frac{ \partial^{2} \boldsymbol{\sigma} }{ \partial v^{2} } &= (0, 0, 0) \\
\frac{ \partial^{2} \boldsymbol{\sigma} }{ \partial u^{2} } &= (x'', y'', 0) \dots 
\end{align}
$$
1st partial derivatives에서 $v$에 대해 한 번 더 미분하면 모든 항이 0이되므로 자명하게 continuous입니다. 실질적으로 $u$에 대해서 미분하는 것들만 살아남습니다.
따라서, 이 partial derivatives들이 continuous조건을 만족하기 위해선, $x, y$또한 smooth조건을 만족해야합니다.
즉, $\alpha(t)$가 Smooth하다면, $\boldsymbol{\sigma}$또한 Smooth함을 확인할 수 있습니다.

3. Surface of revolution(회전면)의 예시를 봅시다.
어떤 plane curve $\alpha(t)$가 다음과 같이 주어져있다고 합시다.
![[SmartSelect_20240416_005000_Samsung Notes.jpg|center|300]]
$$
\alpha(t) = (x(t), y(t))
$$
편의 상 모든 $t$에 대해, $y(t) > 0$라고 가정합시다.
![[SmartSelect_20240416_131913_Samsung Notes.jpg|center|300]]
이 Curve를 한바퀴 돌려서 Surface를 얻었다고 합시다.
이 Surface는 다음과 같이 Parametrize할 수 있습니다.
$$
\boldsymbol{\sigma}(t, \theta) = (x(t), y(t)\cos \theta, y(t)\sin \theta)
$$
$y(t)$가 이 Surface의 반지름 역할을 하기 때문에 다음과 같은 parametrization이 이루어집니다. 이때, $0 < \theta < 2\pi$의 범위를 가집니다.

편미분을 해봅시다.
$$
\begin{align}
\boldsymbol{\sigma}_{t} &= (x'(t), y'(t)\cos \theta, y'(t)\sin \theta) \\
\boldsymbol{\sigma}_{\theta} &= (0, -y(t)\sin \theta, y(t)\cos \theta) \\
\boldsymbol{\sigma}_{t}\times \boldsymbol{\sigma}_{\theta} &= (y'(t)y(t),-x'(t)y(t)\cos \theta, -x'(t)y(t)\sin \theta) \\
\lVert \boldsymbol{\sigma}_{t}\times \boldsymbol{\sigma}_{\theta} \rVert &= \lVert y(t) \rVert \sqrt{ x'^{2} + y'^{2} } = \lVert y(t) \rVert ^{>0} \lVert \alpha'(t) \rVert ^{\neq 0}
\end{align}
$$
따라서, $\lVert \alpha'(t) \rVert\neq 0$, 즉, $\alpha(t)$가 Regular하면 $\boldsymbol{\sigma}$또한 Regular합니다.
$$
\begin{align}
\frac{ \partial^{2} \boldsymbol{\sigma} }{ \partial t^{2} } &= (x''(t), y''(t)\cos \theta,y''(t)\sin \theta) \\
\frac{ \partial^{2} \boldsymbol{\sigma} }{ \partial \theta \partial t } &= (0, -y'(t)\sin \theta, y'(t)\cos \theta) \\
\frac{ \partial^{2} \boldsymbol{\sigma} }{ \partial \theta^{2} } &= (0, -y(t)\cos \theta, -y(t)\sin \theta) \dots\\ 
\end{align}
$$
여기서 영향을 받는 term은 오직 $x, y$뿐이므로, $x(t), y(t)$가 무한 번 미분 가능하면, 즉, Curve $\alpha(t)$가 Smooth하면 $\boldsymbol{\sigma}$또한 Smooth합니다.

## Tangent Plane

$$
\begin{align}
\boldsymbol{\sigma}:U^{\subset \mathbb{R}^{2}} &\to \mathbb{R}^{3} \\
(u,v) &\mapsto (x(u,v), y(u,v), z(u,v))
\end{align}
$$
Parametric Surface $\boldsymbol{\sigma}$가 다음과 같이 주어져 있고, Smooth and Regular하다고 합시다.
이 Plane의 어떤 점 $\mathbf{p} = \boldsymbol{\sigma}(u_{0},v_{0})$에 대해, Tangent Plane을 정의하고자 합니다.
![[SmartSelect_20240416_170321_Samsung Notes.jpg|center|400]]
이 "Plane"은 $\mathbf{p}$를 지나는 Surface $S$위의 모든 Curve들의 Tangent vector들로 구성된 Plane으로 정의해야 자연스러울 것입니다.
![[Pasted image 20240416171428.png|center|200]]
우산을 펼친 모습을 잘 생각해봅시다. 우산 끝 부분의 접평면을 국소적으로 보면 모두 우산살에 의해 만들어짐을 확인할 수 있습니다.
![[SmartSelect_20240416_172236_Samsung Notes.jpg|center|500]]
$t$에서 $U$로 가는 곡선을 $\alpha$, $U$에서 $S$로 가는 Patch를 $\boldsymbol{\sigma}$라고 합시다.
$t$에서 $S$로 가는 공간 상의 곡선을 $\gamma$라고 하면, $\gamma$는 다음과 같습니다.
$$
\begin{align}
\gamma:I^{\subset \mathbb{R}} &\to S^{\subset \mathbb{R}^{3}} \\
t &\xmapsto{\boldsymbol{\sigma}\circ\alpha} (x(u(t),v(t)),y(u(t),v(t)), z(u(t),v(t)))
\end{align}
$$
공간 상의 곡선 $\gamma$의 tangent vector를 구하기 위해, $t$에 대해서 미분을 해봅시다. $\gamma$에 대한 dependency graph를 그리면, 다음과 같은 결과를 얻을 수 있습니다.
$$
\frac{ d \gamma }{ d t } =\frac{ \partial \boldsymbol{\sigma} }{ \partial u } \frac{ du }{ dt } + \frac{ \partial \boldsymbol{\sigma} }{ \partial v } \frac{ dv }{ dt }
$$
이때 $\frac{ \partial \boldsymbol{\sigma} }{ \partial u }$와 $\frac{ \partial \boldsymbol{\sigma} }{ \partial v }$는 vector이고, $\frac{ du }{ dt }$와 $\frac{ dv }{ dt }$는 real number임을 유의합시다.
즉, $\mathbf{p}=(x_{0},y_{0},z_{0})=(x(u_{0},v_{0}), \dots)=(x(u(t_{0}),v(t_{0})),\dots)$에서 Curve $\gamma$에 대한 Tangent vector는 두 벡터  $\frac{ \partial \boldsymbol{\sigma} }{ \partial u }=\left( \frac{ \partial x }{ \partial u },\frac{ \partial y }{ \partial u },\frac{ \partial z }{ \partial u } \right)$와 $\frac{ \partial \boldsymbol{\sigma} }{ \partial v }=\left( \frac{ \partial x }{ \partial v },\frac{ \partial u }{ \partial v },\frac{ \partial z }{ \partial v } \right)$의 선형 조합으로 나타낼 수 있습니다.
이때, patch $\boldsymbol{\sigma}$는 Regular하다는 조건이 있었으므로, 즉, $\frac{ \partial \boldsymbol{\sigma} }{ \partial u }\times \frac{ \partial \boldsymbol{\sigma} }{ \partial v }\neq 0$이므로, $\frac{ \partial \boldsymbol{\sigma} }{ \partial u }$와 $\frac{ \partial \boldsymbol{\sigma} }{ \partial v }$는 서로 linearly independent함을 확인할 수 있습니다.

___
$T_{\mathbf{p}}S$ $=$ the tangent plane of $S$ at $\mathbf{p}=(x_{0}^{=\boldsymbol{\sigma}(u_{0},v_{0})},y_{0},z_{0})$ 로 표기합시다.
그러면 다음과 같은 Theorem이 성립합니다.

> [!Theorem]
> $$T_{\mathbf{p}}S = \mathrm{Span}\left( \frac{ \partial \boldsymbol{\sigma} }{ \partial u }, \frac{ \partial \boldsymbol{\sigma} }{ \partial v }   \right)_{\text{at }(u_{0},v_{0})}$$

**Proof)**
$(\subset)$ 이 방향은 위에서 방금 보였습니다.
$(\supset)$ 임의의 $\mathbf{v} = \lambda \frac{ \partial \boldsymbol{\sigma} }{ \partial u } + \mu \frac{ \partial \boldsymbol{\sigma} }{ \partial v } (\text{at }(u_{0},v_{0}))$를 가져옵시다.
이 vector $\mathbf{v}$가 $T_{\mathbf{p}}S$위에 있다는 뜻은, $\mathbf{p}$를 지나는 어떤 $S$ 위의 곡선 $\gamma$이 존재해서, $\gamma'(t) = \mathbf{v}$가 성립한다는 뜻입니다.
$\gamma(t) = \boldsymbol{\sigma}(\alpha (t)) = \boldsymbol{\sigma}(u_{0} + \lambda(t-t_{0}), v_{0}+\mu(t-t_{0}))$라고 정의합시다.
이 곡선 $\gamma$를 $t$에 관해서 미분해봅시다.

$$
\begin{align}
\gamma'(t)&=\frac{ \partial \boldsymbol{\sigma} }{ \partial u } \cancelto{ \lambda }{ \frac{ du }{ dt } } + \frac{ \partial \boldsymbol{\sigma} }{ \partial v } \cancelto{ \mu }{ \frac{ dv }{ dt }  } \\
&=\lambda \frac{ \partial \boldsymbol{\sigma} }{ \partial u } +\mu \frac{ \partial \boldsymbol{\sigma} }{ \partial v } = \mathbf{v} 
\end{align}
$$
