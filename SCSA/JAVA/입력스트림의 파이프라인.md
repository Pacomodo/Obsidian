---
- 실습 내용
```
ProductDAO인터페이스를 구현한 ProductDAOFile클래스를 완성합니다
파일저장소 : C:\scsa202510\products.txt
파일의 구성
C0001:아메리카노:1000
C0002:아이스아메리카노:1000
C0004:아이스라테:1500
C0003:라테:1500
```
- A번 방법
	1. 파일 연결
	2. 파일 읽기 $\to$ 리스트에 저장
	3. 추가, 수정, 조회, 삭제 시 $\to$ 리스트
	4. 9번 선택 종료 시 리스트 $\to$ 파일에 쓰기
	- Pros
		- B번에 비해 퍼포먼스가 좋음
	- Cons
		- 실시간 반영이 아니기 때문에 외부 사용자가 바로 볼 수 없음
- B번 방법
	1. 추가 기능 선택 $\to$ 파일 연결 $\to$ 파일 읽기 $\to$ 파일 쓰기
	2. 수정 기능 선택 $\to$ 파일 연결 $\to$ 파일 읽기 $\to$ 파일 쓰기
	3. 삭제 기능 선택 $\to$ 파일 연결 $\to$ 파일 읽기 $\to$ 파일 쓰기
	4. 조회 기능 선택 $\to$ 파일 연결 $\to$ 파일 읽기 $\to$ 파일 쓰기
	- Pros
		- 실시간 반영이기 때문에 외부 사용자가 바로 볼 수 있음
	- Cons
		- 매 쿼리마다 파일 조회 $\to$ 퍼포먼스 하락
