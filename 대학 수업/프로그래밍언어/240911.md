```scala
enum Expr:
	case Num(number : BigInt)
	case Add(left: Expr, right: Expr)
	case Mul(left: Expr, right: Expr)
```
Expr은 타입이름
BigInt를 통해 개 큰 수 만들 수 있음 개꿀
For example, an AE expression 1 + (2 * 3) is represented as follows:
```scala
Add(Num(1), Mul(Num(2), Num(3)))
```
