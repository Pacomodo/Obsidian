 >[!Notation]
 >$${<}\mathbf{v}, \mathbf{w}{>} = \mathbf{v}\cdot\mathbf{w}$$

>[!Definition] 
>Let $\mathbf{\beta}(s)$ be a unit speed space curve. (Assume that smooth, regular)
$$\beta : I \rightarrow \mathbb{R}^3(\mathbb{E}^3)$$
$\mathbf{T}(s) = \mathbf{\beta}'(s)$ called **unit tangent vector field**.
$\mathbf{T}'(s) = \mathbf{\beta}''(s)$ called **curvature vector field**.
$\kappa(s) = ||\mathbf{T}'(s)||$ called **curvature function**. In korean, **곡률(휘어짐)**.
$\mathbf{N}(s) = \frac{\mathbf{T}'(s)}{\kappa(s)}$ (Assume that $\kappa(s) > 0$) called **unit principal normal vector field**.
>$\mathbf{B}(s) = \mathbf{T}(s) \times \mathbf{N}(s)$ called **unit binormal vector field**.
>$\tau (s) = - {<}\mathbf{B}'(s), \mathbf{N}(s){>}$ called **torsion**. In korean, **열률(비틀림)**.


___

>[!Theorem] 
>$\mathbf{T}(s), \mathbf{N}(s), \mathbf{B}(s)$ form a **frame field(틀장)** and for each $s \in I$, $\mathbf{T}(s), \mathbf{N}(s), \mathbf{B}(s)$ forms orthonormal basis of $\mathbb{R}^3$.

___

>[!Theorem] Frenet-Serret Formula
$$\begin{pmatrix} \mathbf{T} \\ \mathbf{N} \\ \mathbf{B} \end{pmatrix}' = \begin{pmatrix} 0 & \kappa & 0\\ -\kappa & 0 & \tau \\ 0 & -\tau & 0 \end{pmatrix}\begin{pmatrix} \mathbf{T} \\ \mathbf{N} \\ \mathbf{B} \end{pmatrix}$$

Note that this matrix is skew-symmetric.
___
>[!Recall]
>If $\mathbf{A}^T = \mathbf{A}$, we say $\mathbf{A}$ is symmetric. If $\mathbf{A}^T = -\mathbf{A}$, we say $\mathbf{A}$ is skew-symmetric.
We can express $\mathbf{A}$ into symmetric and skew-symmetric form.
$$\mathbf{A} = \frac{\mathbf{A}+\mathbf{A}^T}{2} + \frac{\mathbf{A} - \mathbf{A}^T}{2}$$

**PROOF of Frenet-Senet formula**)

1) $\mathbf{T}' = \kappa \mathbf{N}$

By definition of $\mathbf{N}$, it proves.

2) $\mathbf{N}' = -\kappa \mathbf{T} + \tau \mathbf{B}$

Recall that $\mathbf{T}, \mathbf{N}, \mathbf{B}$ forms ONB.
So, we can express $\mathbf{N}'$ into $\mathbf{T}, \mathbf{N}, \mathbf{B}$.
Let $\mathbf{N}' = a\mathbf{T} + b\mathbf{N} + c\mathbf{B}$.
Note that ${<}\mathbf{T}, \mathbf{N}'{>} = a {<}\mathbf{T}, \mathbf{T}{>} + b \cancelto{0}{{<}\mathbf{T}, \mathbf{N}{>}} + c \cancelto{0}{{<}\mathbf{T}, \mathbf{B}{>}} = a$.
So, $\mathbf{N}' = {<}\mathbf{T}, \mathbf{N}'{>}\mathbf{T} + {<}\mathbf{N}, \mathbf{N}'{>}\mathbf{N} + {<}\mathbf{B}, \mathbf{N}'{>}\mathbf{B}$

* ${<}\mathbf{T}, \mathbf{N}'{>} = -\kappa$
$$\begin{align}
{<}\mathbf{T}, \mathbf{N}{>} = 0
\xrightarrow{d/ds}&
{<}\mathbf{T}', \mathbf{N}{>} + {<}\mathbf{T}, \mathbf{N}'{>} = 0 \\ \rightarrow {<}\mathbf{T}, \mathbf{N}'{>} &= -{<}\mathbf{T}', \mathbf{N}{>} \\ 
&= -{<}\kappa\mathbf{N}, \mathbf{N}{>} \\
&= -\kappa{<}\mathbf{N}, \mathbf{N}{>}=-\kappa
\end{align}$$
* ${<}\mathbf{N}, \mathbf{N}'{>} = 0$
$$\begin{align}
||\mathbf{N}|| = 1 \rightarrow&
{<}\mathbf{N}, \mathbf{N}{>} = 1 \\
\xrightarrow{d/ds}&
\mathbf{N}'\cdot\mathbf{N} + \mathbf{N}\cdot\mathbf{N}' = 0 \\
\rightarrow&
\mathbf{N}\cdot\mathbf{N}'=0
\end{align}$$
* ${<}\mathbf{B}, \mathbf{N}'{>} = \tau$
$$\begin{align}
&{<}\mathbf{B}, \mathbf{N}{>} = 0 \\
\xrightarrow{d/ds}&
{<}\mathbf{B}', \mathbf{N}{>} + {<}\mathbf{B}, \mathbf{N}'{>} = 0 \\
\rightarrow&
{<}\mathbf{B}, \mathbf{N}'{>} = -{<}\mathbf{B}', \mathbf{N}{>} = \tau (\because \textrm{def of } \tau)
\end{align}$$

**Claim**: $\mathbf{\beta}(s)$ is **completely** determined by $\kappa(s)$ and $\tau(s)$. (up to translation & rotation)

___

**THEOREM**)
Let $\mathbf{\alpha}(t)$ : smooth, regular. Then,
$$\mathbf{\alpha}(t):\textrm{line} \Leftrightarrow \kappa(s) = 0$$

___

**PROOF**)
$(\Leftarrow)$ $\kappa (s) = ||\mathbf{T}'(s)|| = ||\mathbf{\beta}''(s)|| = 0$
$\xrightarrow{\int}$ $\mathbf{\beta}'(s) = \mathbf{v}(\textrm{constant vector}) = (p, q, r)$
$\xrightarrow{\int}$ $\mathbf{\beta}(s) = \mathbf{v}s + \mathbf{v}_0 = (ps+p_0, qs+q_0, rs+r_0)$.
So, $\mathbf{\alpha}(t)$ is a line.

$(\Rightarrow)$ $\mathbf{\alpha}(t) = \mathbf{v}t + \mathbf{v}_0$
$\xrightarrow{\textrm{arc length parametrization}}$ $s = \int_0^t ||\mathbf{\alpha}'(u)|| du = ||\mathbf{v}||t$
$\xrightarrow{\textrm{take inverse function}} t = \frac{s}{||\mathbf{v}||}$
$\xrightarrow{\textrm{reparametrize}} \mathbf{\beta}(s) = \mathbf{v}\left(\frac{s}{||\mathbf{v}||}\right) + \mathbf{v}_0$
$\xrightarrow{d/ds}\mathbf{\beta}'(s) = \frac{\mathbf{v}}{||\mathbf{v}||}$
$\xrightarrow{d/ds} \mathbf{\beta}''(s) = \mathbf{0} \rightarrow \kappa(s) = 0$

___

**THEOREM**)
Let $\mathbf{\beta}(s)$ : unit speed curve and $\kappa > 0$. Then,
$$\mathbf{\beta}:\textrm{plane curve} \Leftrightarrow \tau(s) \equiv 0$$

___

**PROOF**)

$(\Rightarrow)$ Suppose $\mathbf{\beta}(s)$ be a plane curve.
Then, there are $\mathbf{p}$ & $\mathbf{n}$ such that $\mathbf{n}$ is normal vector of plane, $\mathbf{p}$ is any point on plane and ${<}\mathbf{\beta}(s) - \mathbf{p}, \mathbf{n}{>} = 0$.
$\xrightarrow{d/ds}{<}\mathbf{\beta}'(s), \mathbf{n}{>} + \cancelto{0}{{<}\mathbf{\beta}(s) - \mathbf{p}, \mathbf{0}{>}} = 0$
$\rightarrow {<}\mathbf{\beta}'(s), \mathbf{n}{>} = 0$. ($\mathbf{T}(s) = \mathbf{\beta}'(s) \perp \mathbf{n}$)
$\xrightarrow{d/ds}{<}\mathbf{\beta}''(s), \mathbf{n}{>} + \cancelto{0}{{<}\mathbf{\beta}'(s), \mathbf{0}{>}} = 0$
$\rightarrow {<}\mathbf{\beta}''(s), \mathbf{n}{>} = 0$. ($||\mathbf{\beta}''(s)||\mathbf{N}(s) = \mathbf{\beta}''(s) \perp \mathbf{n}$)
Therefore, $\mathbf{n}$ is orthogonal to both $\mathbf{T}(s)$ & $\mathbf{N}(s)$.
Since $\mathbf{B}(s)$ is unit vector that $\mathbf{B}(s) = \mathbf{T}(s) \times \mathbf{N}(s)$, $\frac{\mathbf{n}}{||\mathbf{n}||} = \pm \mathbf{B} = \textrm{constant}$.
Therefore, $\tau (s) = -{<}\mathbf{B}'(s), \mathbf{N}(s){>} = -{<}0, \mathbf{N}(s){>} = 0$.

$(\Leftarrow)$ If $\tau(s) \equiv 0$, then, $-{<}\mathbf{B}'(s), \mathbf{N}(s){>} = 0$.
**Claim**: $\mathbf{B}'(s) = -\tau \mathbf{N}(s) \equiv \mathbf{0}$
Why not $\mathbf{N}(s) = \mathbf{0}$? if so, $\mathbf{N}(s) = \frac{\mathbf{T}'(s)}{\kappa(s)} \Rightarrow \mathbf{T}'(s) = \mathbf{0}$. But we assumed that $\kappa(s) \neq 0 \Rightarrow ||\mathbf{T}'(s)|| \neq 0$. $(\rightarrow\leftarrow)$
So, $\mathbf{B}(s) = \mathbf{B} \textrm{(constant vector)}$
Consider $f(s) = {<}\mathbf{\beta}(s) - \mathbf{\beta}(0), \mathbf{B}{>}$.
Then, $f'(s) = {<}\mathbf{\beta}'(s), \mathbf{B}{>} + \cancelto{0}{{<}\mathbf{\beta}(s) - \mathbf{\beta}(0), \mathbf{0}{>}} ={<}\mathbf{T}(s), \mathbf{B}{>} = 0$.
Note that $f(0) = 0, f'(s) = 0$ for all $s$.
Therefore, $f(s) = {<}\mathbf{\beta}(s) - \mathbf{\beta}(0), \mathbf{B}{>} = 0$ for all $s$.
So, $\mathbf{\beta}(s)$ is a curve on a plane that normal vector is $\mathbf{B}$.

**THEOREM**)
Let $\mathbf{\beta}(s)$ : unit speed curve, $\kappa(s) > 0$ be constant, $\tau (s) \equiv 0$.
Then $\mathbf{\beta}(s)$ is a (part of) circle.

___

**PROOF**)

By previous theorem, we know that $\mathbf{\beta}(s)$ is a plane curve.
Consider $\mathbf{\gamma}(s) = \mathbf{\beta}(s) + \frac{\mathbf{N}(s)}{\kappa(s)}$.
Since $\mathbf{\beta}(s)$ is on a plane made be $\mathbf{T}$ and $\mathbf{N}$, $\mathbf{\gamma}(s)$ is on a same plane.
$\mathbf{\gamma}'(s) = \mathbf{\beta}'(s) + \frac{\mathbf{N}'(s)}{\kappa(s)} \overset{\textrm{by F-S formula}}{=} \mathbf{\beta}'(s) + \frac{-\kappa(s)\mathbf{T}(s)}{\kappa(s)} = \mathbf{T}(s) - \mathbf{T}(s) = 0$.
So, $\mathbf{\gamma}(s) = \mathbf{c} \textrm{(constant vector)}$.
$\rightarrow \mathbf{c} = \mathbf{\beta}(s) + \frac{\mathbf{N}(s)}{\kappa(s)}$
$\rightarrow ||\mathbf{\beta}(s) - \mathbf{c}|| = ||-\frac{\mathbf{N}(s)}{\kappa(s)}||$
$\rightarrow ||\mathbf{\beta}(s) - \mathbf{c}|| = \frac{1}{\kappa(s)}$
Hence, $\mathbf{\beta}(s)$ is part of a circle.
