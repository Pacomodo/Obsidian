## Parametric Surface

우리는 Parametric Surface에 대해서 공부를 하고 있습니다. 사실은 Surface라는 큰 맥락에서 생각할 수 있는데, 이를 테면, Torus라던지, Sphere라던지, 그거는 한 조각으로 표현할 수 없지만, 어쨌든 우리는 Local한 한 조각만을 보고 있습니다. 즉, 일부분만 보고 있습니다.
어떤 $\mathbb{R}^2$의 Open subset $U$에서 $\mathbb{R}^{3}$로 가는 함수 $\boldsymbol{\sigma}$를 생각해봅시다.
$$
\begin{align}
\boldsymbol{\sigma}: U & \to \mathbb{R}^{3} \\
(u,v) & \mapsto (x(u,v), y(u,v), z(u,v))
\end{align}
$$
![[SmartSelect_20240414_014725_Samsung Notes.jpg|center|400]]
이 평면 조각이 저쪽으로 굽어져 들어가는, 이변수 벡터함수입니다. $\boldsymbol{\sigma}$의 image가 이 부분의 Surface라고 생각하면 됩니다. 더 정확히 말하면 Surface Patch입니다. 우리는 이 부분에서 벌어지는 일만 생각할 것입니다.

## Tangent Plane
Tangent plane to $S$ at $\mathbf{p}=(x_{0},y_{0},z_{0})$는 다음과 같이 정의했습니다.
$$
T_{\mathbf{p}}S = \left\{ \gamma'(t_{0})|\gamma'(t_{0})=\boldsymbol{\sigma}_{u}(u_{0},v_{0})\frac{ du }{ dt } + \boldsymbol{\sigma}_{v}(u_{0},v_{0}) \frac{ dv }{ dt } = \lambda \boldsymbol{\sigma}_{u}+\mu \boldsymbol{\sigma}_{v} \right\}
$$
![[SmartSelect_20240416_172236_Samsung Notes.jpg|center|500]]
이때, $\gamma(t) = \boldsymbol{\sigma}(\alpha(t)) = \boldsymbol{\sigma}(u(t),v(t))=(x(u(t),v(t)),y(u(t),v(t)),z(u(t),v(t)))$입니다.
![[Pasted image 20240416195123.png|center|100]]
이를 dependency graph를 활용하여 미분하면, 다음과 같습니다.
$$
\frac{d\gamma}{dt}=\frac{ \partial \boldsymbol{\sigma} }{ \partial u } \frac{ du }{ dt } +\frac{ \partial \boldsymbol{\sigma} }{ \partial v } \frac{ dv }{ dt }
$$
$t=t_{0}$일 때 $(u_{0},v_{0})$를 지난다고 하면, 다음과 같이 쓸 수 있습니다.
$$
\frac{d\gamma}{dt}_{\text{at }t=t_{0}} = \boldsymbol{\sigma}_{u}(u_{0},v_{0})u'(t_{0}) + \boldsymbol{\sigma}_{v}(u_{0},v_{0}) v'(t_{0})
$$


> [!Theorem]
> $$\begin{align}T_{\mathbf{p}}S &= \mathrm{Span}\{\boldsymbol{\sigma}_{u}(u_{0},v_{0}), \boldsymbol{\sigma}_{v}(u_{0},v_{0})\} \\
&=\{\lambda \boldsymbol{\sigma}_{u}(u_{0},v_{0})+\mu \boldsymbol{\sigma}_{v}(u_{0},v_{0})|\lambda,\mu \in \mathbb{R}^{2}\}\end{align}$$


$\boldsymbol{\sigma}$가 Regular라는 조건은 $\lVert \boldsymbol{\sigma}_{u}\times \boldsymbol{\sigma}_{v} \rVert \neq 0$과 동치였고, 이는 $\boldsymbol{\sigma}_{u}$와 $\boldsymbol{\sigma}_{v}$가 서로 linearly independent하다는 조건과 동치였습니다.
따라서, $\lambda \boldsymbol{\sigma}_{u}(u_{0},v_{0})+\mu \boldsymbol{\sigma}_{v}(u_{0},v_{0})$는 2차원 subspace, 즉, plane을 형성합니다.
![[SmartSelect_20240416_205656_Samsung Notes.jpg|center|400]]
Tangent plane의 parametric expression은 다음과 같습니다.
$$
\mathbf{x}(\lambda,\mu)=(x_{0},y_{0},z_{0})+\lambda \boldsymbol{\sigma}_{u}(u_{0},v_{0}) + \mu \boldsymbol{\sigma}_{v}(u_{0},v_{0})
$$
즉,
$$
(x-x_{0},y-y_{0},z-z_{0}) = \lambda \boldsymbol{\sigma}_{u} + \mu \boldsymbol{\sigma}_{v}
$$
로 표현할 수 있습니다. plane을 형성하는 basis인 $\boldsymbol{\sigma}_{u}$와 $\boldsymbol{\sigma}_{v}$를 Cross-product하면 plane의 normal vector를 얻을 수 있습니다.
즉, plane의 normal vector는 $\boldsymbol{\sigma}_{u}\times \boldsymbol{\sigma}_{v}$임을 쉽게 알 수 있습니다.
![[Pasted image 20240416204442.png|center|400]]
$$
\boldsymbol{\sigma}_{u}\times \boldsymbol{\sigma}_{v}\text{ at }(u_{0},v_{0}) = \text{normal vector to the tangent plane}
$$
이를 통해 Curve에서 했던 것과 비슷하게, unit normal vector field를 정의할 수 있습니다.
$$
\mathbf{N}_{\text{ at }(u_{0},v_{0})} = \frac{\boldsymbol{\sigma}_{u}\times \boldsymbol{\sigma}_{v}}{\lVert \boldsymbol{\sigma}_{u}\times \boldsymbol{\sigma}_{v} \rVert }_{\text{ at }(u_{0},v_{0})}
$$

## Example

Level surface $S: F(x,y,z) = C$에서의 예시를 봅시다. 예를 들자면, sphere, $x^{2}+y^{2}+z^{2}=c^{2}$와 같은 surface입니다.
![[Pasted image 20240416213305.png|center|300]]
어떤 공간 곡선 $\alpha(t) = (x(t),y(t),z(t))$가 Level surface $S$위에 존재하면, $F(x(t), y(t), z(t))=C$를 만족할 것입니다.
이를 미분해봅시다.
![[Pasted image 20240416213753.png|center|150]]
$F$에 대한 dependency graph는 다음과 같습니다. 이를 활용하여 미분하면 다음과 같은 결과를 얻을 수 있습니다.
$$
\begin{align}
\frac{ dF }{ dt } = \frac{ \partial F }{ \partial x } \frac{ dx }{ dt } +\frac{ \partial F }{ \partial y } \frac{ dy }{ dt } + \frac{ \partial F }{ \partial z } \frac{ dz }{ dt } &= 0\\
\left( \frac{ \partial F }{ \partial x } ,\frac{ \partial F }{ \partial y }, \frac{ \partial F }{ \partial z }  \right) \cdot\left( \frac{ dx }{ dt } ,\frac{ dy }{ dt } ,\frac{ dz }{ dt }  \right) &=0 
\end{align}
$$
이때, $\left( \frac{ dx }{ dt },\frac{ dy }{ dt },\frac{ dz }{ dt } \right) = \alpha'(t)$, 즉, 공간 곡선 $\alpha(t)$의 tangent vector임을 알 수 있습니다.
또한, $\left( \frac{ \partial F }{ \partial x },\frac{ \partial F }{ \partial y },\frac{ \partial F }{ \partial z } \right) = \nabla F$, 즉, $F$의 gradient입니다.
$t=t_{0}$일 때 $(x_{0},y_{0},z_{0})$를 지난다고 해봅시다.
$$
\begin{align}
\left( \frac{ \partial F }{ \partial x } ,\frac{ \partial F }{ \partial y }, \frac{ \partial F }{ \partial z }  \right)_{\text{at }(x_{0},y_{0},z_{0})} \cdot\left( \frac{ dx }{ dt } ,\frac{ dy }{ dt } ,\frac{ dz }{ dt }  \right)_{\text{at }t_{0}} &= 0 \\
\nabla F(x_{0},y_{0},z_{0}) \cdot \alpha'(t_{0}) &=0 
\end{align}
$$
$\nabla F(x_{0},y_{0},z_{0}) \cdot \alpha'(t_{0})=0$이라는 뜻은 $\nabla F \perp \alpha'(t)$라는  한뜻이고, 이는 $\nabla F(x_{0},y_{0},z_{0})$가 Surface $S$위의 점 $(x_{0},y_{0},z_{0})$에는 한뜻이고, 이는 $\nabla F(x_{0},y_{0},z_{0})$가 Surface 위의 점서의 tangent plane에 수직,즉, normal vector라는 사실을 알 수 있습니다.
따라서, Level surface $S$에 대한 unit normal vector field는 다음과 같이 정의됩니다.
$$
\mathbf{N} = \frac{\nabla F}{\lVert \nabla F \rVert }_{\neq 0}
$$
따라서, 이 Level surface $S$가 Regular할 조건은, $S$위의 모든 $(x,y,z)$에 대하여 $\nabla F \neq \mathbf{0}$일 조건과 같습니다.

## First Fundamental Form

제 1 기본형, First fundamental form에 대해서 배워봅시다.
어떤 Parametric Surface
$$
\begin{align}
\boldsymbol{\sigma}:U &\to \mathbb{R}^{3} \\
(u,v) &\mapsto (x(u,v),y(u,v),z(u,v))
\end{align}
$$
가 주어져 있다고 합시다.

이때, $E, F, G$는 다음과 같이 정의됩니다.

> [!Definition]
> $$\begin{align}E &:= \boldsymbol{\sigma}_{u}\cdot \boldsymbol{\sigma}_{u} \\F &:= \boldsymbol{\sigma}_{u}\cdot \boldsymbol{\sigma}_{v} \\G &:= \boldsymbol{\sigma}_{v}\cdot \boldsymbol{\sigma}_{v}\end{align}$$


이때, $$
\begin{align}
\boldsymbol{\sigma}_{u} &= \left( \frac{ \partial x }{ \partial u } ,\frac{ \partial y }{ \partial u }, \frac{ \partial z }{ \partial u }  \right) \\
\boldsymbol{\sigma}_{v} &= \left( \frac{ \partial x }{ \partial v } ,\frac{ \partial y }{ \partial v } ,\frac{ \partial z }{ \partial v }  \right)
\end{align}
$$이고, 각각의 $\boldsymbol{\sigma}_{u},\boldsymbol{\sigma}_{v}$들은 $U \to \mathbb{R}^{3}$로 가는 함수임을 생각하면, $E,F,G$는 $$
\begin{align}
E &:= \boldsymbol{\sigma}_{u}\cdot \boldsymbol{\sigma}_{u} = \left( \frac{ \partial x }{ \partial u }  \right)^{2}+\left( \frac{ \partial y }{ \partial u }  \right)^{2}+ \left( \frac{ \partial z }{ \partial u }  \right)^{2} \\
F &:= \boldsymbol{\sigma}_{u}\cdot \boldsymbol{\sigma}_{v} = \left( \frac{ \partial x }{ \partial u }  \right)\left( \frac{ \partial x }{ \partial v }  \right)+\left( \frac{ \partial y }{ \partial u }  \right)\left( \frac{ \partial y }{ \partial v }  \right)+ \left( \frac{ \partial z }{ \partial u }  \right)\left( \frac{ \partial z }{ \partial v }  \right) \\
G &:= \boldsymbol{\sigma}_{v}\cdot \boldsymbol{\sigma}_{v} =\left( \frac{ \partial x }{ \partial v }  \right)^{2}+\left( \frac{ \partial y }{ \partial v }  \right)^{2}+\left( \frac{ \partial z }{ \partial v }  \right)^{2}
\end{align}
$$ 두 vector $\boldsymbol{\sigma}_{u}, \boldsymbol{\sigma}_{v}$를 dot product한 것이므로, $U \to \mathbb{R}$로 가는 함수들로 생각할수 있습니다.
그리고 $E, F, G$를 First fundamental form에 나타나는 계수, 즉, First fundamental coefficient라고 부릅니다.

보통 수학에서, 특히 대수에서 자주 사용되는, Form이라는 용어는 동차식을 의미합니다. 선형 대수에서 Bilinear form, Quadratic form 등을 배웠던 것을 떠올려봅시다. Bilinear form은 innerproduct랑 형태가 비슷한데, ${<}\mathbf{v}, \mathbf{w}{>} = \mathbf{v}^{T}A\mathbf{w}$꼴로 쓰여져, 두 벡터를 하나의 실수 $\mathbb{R}$로 보내는 map이었습니다. Quadratic form은 $\mathbf{v}$하나를 받아 $\mathbf{v}^{T}A\mathbf{v}$로 보내는 형태였습니다.

___
그래서 form을 만들어 봅시다.

$\mathbf{p} = \boldsymbol{\sigma}(u_{0},v_{0})=(x_{0},y_{0},z_{0})$인 점에서 Tangent plane $T_{\mathbf{p}}\boldsymbol{\sigma}$를 만들었다고 하고, 어떤 vector $\mathbf{v}$가 $T_{\mathbf{p}}\boldsymbol{\sigma}$위에 있다고 해봅시다.
즉,
$$\mathbf{v}={\lambda \boldsymbol{\sigma}_{u}(u_{0},v_{0}) + \mu \boldsymbol{\sigma}_{v}(u_{0},v_{0})}^{\in \mathbb{R}^{3}}$$
라고 해 봅시다.

또한, plane $T_{\mathbf{p}}\boldsymbol{\sigma}$에 있는 또 다른 vector $\mathbf{w} = \lambda'\boldsymbol{\sigma}_{u}(u_{0},v_{0})+\mu'\boldsymbol{\sigma}_{v}(u_{0},v_{0})$가 있다고 합시다.
($\lambda, \mu$를 미분한 것이 아니라, 또 다른 계수를 나타낸 것입니다.)

이 두 vector $\mathbf{v}, \mathbf{w}$를 inner product하면 다음과 같습니다.
$$
\begin{align}
{<}\mathbf{v},\mathbf{w}{>} &= {<}\lambda \boldsymbol{\sigma}_{u}+\mu \boldsymbol{\sigma}_{v}, \lambda'\boldsymbol{\sigma}_{u}+\mu'\boldsymbol{\sigma}_{v}{>}_{\text{at }(u_{0},v_{0})} \\
&= \lambda \lambda'{<}\boldsymbol{\sigma}_{u},\boldsymbol{\sigma}_{u}{>} + (\lambda \mu'+\mu \lambda'){<}\boldsymbol{\sigma}_{u}, \boldsymbol{\sigma}_{v}{>} + \mu \mu'{<}\boldsymbol{\sigma}_{v}, \boldsymbol{\sigma}_{v}{>} \\
&= \lambda \lambda' E +(\lambda \mu'+\mu \lambda')F + \mu \mu'G
\end{align}
$$
이를 First fundamental Form이라고 부릅니다.

만약 $\mathbf{v}=\mathbf{w}$라면, $\lambda = \lambda', \mu=\mu'$이므로, Form은 다음과 같이 쓰여질 수 있습니다.
$$
\begin{align}
{<}\mathbf{v},\mathbf{w}{>} = {<}\mathbf{v},\mathbf{v}{>} &= \lambda^{2}E + 2\lambda \mu F + \mu^{2}G _{\text{ at}(u_{0},v_{0})} \\
&=Edu^{2}+2Fdudv+Gdv^{2}
\end{align}
$$
여기서, $du, dv$는 함수인데, $T_{\mathbf{p}}S$의 원소 $\mathbf{v}$를 받아, 그 계수 $\lambda, \mu$를 내보내는 함수입니다.
즉, $du(\mathbf{v})=\lambda, dv(\mathbf{v})=\mu$입니다.
다시 말하면, $du, dv$는 다음과 같은 함수입니다.
$$
\begin{align}
du : T_{\mathbf{p}}\boldsymbol{\sigma} &\to \mathbb{R} \\
(\mathbf{v}=\lambda \boldsymbol{\sigma}_{u}+\mu \boldsymbol{\sigma}_{v})_{\text{ at }(u_{0},v_{0})} &\mapsto \lambda \\
dv : T_{\mathbf{p}}\boldsymbol{\sigma} &\to \mathbb{R} \\
(\mathbf{v}=\lambda \boldsymbol{\sigma}_{u}+\mu \boldsymbol{\sigma}_{v})_{\text{ at }(u_{0},v_{0})} &\mapsto \mu
\end{align}
$$

___

왜 이렇게 쓰는지 생각해봅시다. 미적분학 시간에 linear approximation을 했던 것을 잘 떠올려봅시다.

___

위의 식을 행렬 형태로 쓰면 다음과 같습니다.
$$
\begin{align}
{<}\mathbf{v},\mathbf{v}{>} &= \lambda^{2}E+2\lambda \mu F+\mu^{2}G \\
&= \begin{pmatrix}
\lambda  & \mu
\end{pmatrix} \begin{pmatrix}
E & F \\
F & G
\end{pmatrix} \begin{pmatrix}
\lambda \\
\mu
\end{pmatrix} \\
I &= \begin{pmatrix}
du  & dv
\end{pmatrix}\begin{pmatrix}
E & F \\
F & G
\end{pmatrix}\begin{pmatrix}
du \\
dv
\end{pmatrix}
\end{align}
$$
여기서 $du, dv$는 $T_{\mathbf{p}}S$의 원소 $\mathbf{v}$에서 나왔음을 생각합시다.

즉, 지금까지 했던 내용을 정리하자면 다음과 같습니다.

어떤 Surface patch $\boldsymbol{\sigma}$가 다음과 같이 주어져 있다고 합시다.
$$
\begin{align}
\boldsymbol{\sigma}: U &\to \mathbb{R}^{3} \\
(u,v) &\mapsto (x(u,v),y(u,v),z(u,v))
\end{align}
$$
각 $\boldsymbol{\sigma}$의 편미분들은 다음과 같이 정의됩니다.
$$
\begin{align}
\boldsymbol{\sigma}_{u} &= \left( \frac{ \partial x }{ \partial u } ,\frac{ \partial y }{ \partial u } ,\frac{ \partial z }{ \partial u }  \right) \\
\boldsymbol{\sigma}_{v} &= \left( \frac{ \partial x }{ \partial v } ,\frac{ \partial y }{ \partial v } ,\frac{ \partial z }{ \partial v }  \right)
\end{align}
$$
이때, $E,F,G$는 $U \to \mathbb{R}$로 가는 다음과 같은 함수입니다.
$$
\begin{align}
E &:= {<}\boldsymbol{\sigma}_{u},\boldsymbol{\sigma}_{u}{>} \\
F &:= {<}\boldsymbol{\sigma}_{u},\boldsymbol{\sigma}_{v}{>} \\
G &:= {<}\boldsymbol{\sigma}_{v},\boldsymbol{\sigma}_{v}{>}
\end{align}
$$
이 $E, F, G$를 First Fundamental Form coefficient라고 합니다.
$\mathbf{v}\in T_{\mathbf{p}}S$의 First fundamental form은 다음과 같이 쓸 수 있습니다.
$$
\begin{align}
I &= {<}\mathbf{v}, \mathbf{v}{>} \\
&= \begin{pmatrix}
\lambda & \mu
\end{pmatrix}\begin{pmatrix}
E & F \\
F & G
\end{pmatrix}\begin{pmatrix}
\lambda \\
\mu
\end{pmatrix}=\begin{pmatrix}
du & dv
\end{pmatrix}\begin{pmatrix}
E & F \\
F & G
\end{pmatrix}\begin{pmatrix}
du \\
dv
\end{pmatrix}
\end{align}
$$
where $\mathbf{v}=\lambda \boldsymbol{\sigma}_{u}(u_{0},v_{0})+\mu \boldsymbol{\sigma}_{v}(u_{0},v_{0})$.

___

> [!Theorem]
> $$EG-F^{2} = \lVert \boldsymbol{\sigma}_{u}\times \boldsymbol{\sigma}_{v} \rVert ^{2} \text{ at each }(u,v)$$

**Proof)**

$$
\begin{align}
EF-G^{2}&=(\boldsymbol{\sigma}_{u}\cdot \boldsymbol{\sigma}_{u})(\boldsymbol{\sigma}_{v}\cdot \boldsymbol{\sigma}_{v})-(\boldsymbol{\sigma}_{u}\cdot \boldsymbol{\sigma}_{v})^{2} \\
(\because \boldsymbol{\sigma}\text{ is regular, so, }\lVert \boldsymbol{\sigma}_{u}\times \boldsymbol{\sigma}_{v} \rVert \neq 0)&= \lVert \boldsymbol{\sigma}_{u} \rVert ^{2} \lVert \boldsymbol{\sigma}_{v} \rVert ^{2}\left( 1-\frac{(\boldsymbol{\sigma}_{u}\cdot \boldsymbol{\sigma}_{v})^{2}}{\lVert \boldsymbol{\sigma}_{u} \rVert ^{2}\lVert \boldsymbol{\sigma}_{v} \rVert ^{2}} \right) \\
&=\lVert \boldsymbol{\sigma}_{u} \rVert ^{2}\lVert \boldsymbol{\sigma}_{v} \rVert ^{2}\left( 1-\left( \frac{\boldsymbol{\sigma}_{u}\cdot \boldsymbol{\sigma}_{v}}{\lVert \boldsymbol{\sigma}_{u} \rVert \cdot \lVert \boldsymbol{\sigma}_{v} \rVert } \right)^{2} \right) \\
&= \lVert \boldsymbol{\sigma}_{u} \rVert ^{2} \lVert \boldsymbol{\sigma}_{v} \rVert ^{2}(1-\cos ^{2}\theta) \\
&= \lVert \boldsymbol{\sigma}_{u} \rVert ^{2}\lVert \boldsymbol{\sigma}_{v} \rVert ^{2}\sin ^{2}\theta \\
&= \lVert \boldsymbol{\sigma}_{u}\times \boldsymbol{\sigma}_{v} \rVert ^{2}
\end{align}
$$

___
어떤 곡면의 넓이를 구하는 공식을 다시 상기시켜봅시다.
이는 다음과 같이 쓸 수 있습니다.
$$
A(S)=\iint_{U}\lVert \boldsymbol{\sigma}_{u}\times \boldsymbol{\sigma}_{v} \rVert dudv
$$
위의 정리를 활용하면, 위의 공식을 first fundamental coefficient로 나타낼 수 있습니다.
$$
= \iint_{U}\sqrt{ EG - F^{2} }dudv
$$
곡선에서는 $\kappa$와 $\tau$가 곡선을 결정짓는 것 처럼, 곡면에서는 $E,F,G$가 곡면을 결정짓습니다.

___

![[Pasted image 20240419160636.png|center|400]]
어떤 곡면 $\boldsymbol{\sigma}$ 위의 곡선 $\gamma$를 생각해봅시다.
$$
\begin{align}
\gamma(t) &= \boldsymbol{\sigma}(u(t),v(t)) \\
\gamma'(t) &= \frac{ \partial \boldsymbol{\sigma} }{ \partial u } \frac{ du }{ dt } +\frac{ \partial \boldsymbol{\sigma} }{ \partial v } \frac{ dv }{ dt }  \\
\lVert \gamma'(t) \rVert ^{2} &= \gamma'(t)\cdot \gamma'(t) \\
&= {<}\frac{ \partial \boldsymbol{\sigma} }{ \partial u } \frac{ du }{ dt } +\frac{ \partial \boldsymbol{\sigma} }{ \partial v } \frac{ dv }{ dt },\frac{ \partial \boldsymbol{\sigma} }{ \partial u } \frac{ du }{ dt } +\frac{ \partial \boldsymbol{\sigma} }{ \partial v } \frac{ dv }{ dt }{>} \\
&= \underbrace{ \frac{ \partial \boldsymbol{\sigma} }{ \partial u } \cdot \frac{ \partial \boldsymbol{\sigma} }{ \partial u }  }_{ E }\left( \frac{ du }{ dt }  \right)^{2}+2\underbrace{ \frac{ \partial \boldsymbol{\sigma} }{ \partial u } \cdot \frac{ \partial \boldsymbol{\sigma} }{ \partial v }  }_{ F }\left( \frac{ du }{ dt } \frac{ dv }{ dt }  \right)+\underbrace{ \frac{ \partial \boldsymbol{\sigma} }{ \partial v } \cdot \frac{ \partial \boldsymbol{\sigma} }{ \partial v }  }_{ G }\left( \frac{ dv }{ dt }  \right)^{2}
\end{align}
$$
이 곡선 $\gamma(t)$에 대한 길이 공식을 떠올려봅시다.
$$
L(\gamma) = \int_{\alpha}^{\beta}\lVert \gamma'(t) \rVert dt 
$$
위의 공식을 활용하여, 이를 $E,F,G$를 활용한 식으로 변형할 수 있습니다.
$$
L(\gamma)=\int _{\alpha}^{\beta} \sqrt{ E\left( \frac{ du }{ dt }  \right)^{2}+2F\left( \frac{ du }{ dt }  \right)\left( \frac{ dv }{ dt }  \right)+G\left( \frac{ dv }{ dt }  \right)^{2} } dt 
$$
