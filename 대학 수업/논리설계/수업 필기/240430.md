## Hardware Description Languages II

### Combinational Blocks

#### Combinational Logic Using `always`

Recall that `assign` statement.
LHS signal is changed when RHS signal is changed.

* `always` statement
	* Whenever the event in sensitivity list occurs, the statements inside of an `always` statements inside of an `always` statement are executed.
```systemverilog
	module example(
	...
		always @ (sensitivity list) begin
		    statement 1;
		    statement 2;
		    ...
		end
	endmodule
	```
* `always` statement(system verilog)
	 * `always_comb` : for combinational logic
	 * `always_ff` : for sequential logic
	 * `always_latch` : for latch design
* Example
```systemverilog
	module bitwise_ops (
    input  logic [3:0] a, b,
    output logic [3:0] y1, y2, y3, y4, y5, y6, y7);
    /* always_comb statement need begin/end 
       because there are more than one statements in always */
    always_comb begin // always @ (*)와 같다. * means all inputs.(a,b)
    // So, it means if a is changed or b is changed, then ~ execute~~~...
        y1 = ~a;
        y2 = a & b;
        y3 = a | b;
        y4 = a ^ b;
        y5 = a ~& b;  // y5 = ~(a & b);
        y6 = a ~| b;  // y6 = ~(a | b);
        y7 = a ~^ b;  // y7 = ~(a ^ b);
   end
   /*
   assign statement를 사용한 것과 동일한 결과가 나온다.
   always statement executed sequentially. like the normal programming language.
    This module could be described with assign statements using fewer 
lines of codes, so it’s better to use assign statements in this case.
   */
endmodule
```
```verilog
module bitwise_ops (a, b, y1, y2, y3, y4, y5, y6, y7);
    input  [3:0] a, b;
    output [3:0] y1, y2, y3, y4, y5, y6, y7;

    reg    [3:0] y1, y2, y3, y4, y5, y6, y7;
    // always needs to drive reg types only
    always @ (a or b) begin
        y1 = ~a;
        y2 = a & b;
        y3 = a | b;
        y4 = a ^ b;
        y5 = a ~& b;  // y5 = ~(a & b);
        y6 = a ~| b;  // y6 = ~(a | b);
        y7 = a ~^ b;  // y7 = ~(a ^ b);
   end
Endmodule
```

#### `if/else` statement

* `if/else` statement
	* Based on the result of condition, statement A or statement B is executed.
``` systemverilog
module example (
    ……
    always_comb begin
        if (condition)
            statement A;
        else
            statement B;
    end

endmodule
```
* `if/else` conditions should be defined for all possible input conditions!!
* Otherwise, latches will be generated ($\leftarrow$ BUG!!!).
* Example
```systemverilog
module example_bug (
    input logic [1:0] a,
    …… );

    always_comb begin
        if (a==2’b00)
            statement A;
        else if (a==2’b01)
            statement B;
        else if (a==2’b10)
            statement C;
    end

endmodule
```
```systemverilog
module example (
   ……
   always_comb begin
      if (condition) begin
          statement A1;
          statement A2;
          ……
      end else begin
          statement B1;
          statement B2;
          ……
      end
   end

endmodule
```

#### `case` statement
Similar to `switch` in C.
* `case` statement
	* Implies combinational logic only if all possible input combinations described
	* Remember to use a default statement when necessary (when all possible combinations are not listed)
* Example
```systemverilog
module example (
    ……
    always_comb begin
        case (variable)
            condition 0: statement A;
            condition 1: statement B;
            condition 2: statement C;
            default: statement D;
        endcase
    end

endmodule
```
```systemverilog
module sevenseg ( input  logic [3:0] num,
                  output logic [6:0] seg );

    always_comb begin
        case (num)
            0: seg = 7’b111_1110;
            1: seg = 7'b011_0000;
            2: seg = 7'b110_1101;
            3: seg = 7'b111_1001;
            4: seg = 7'b011_0011;
            5: seg = 7'b101_1011;
            6: seg = 7'b101_1111;
            7: seg = 7'b111_0000;
            8: seg = 7'b111_1111;
            9: seg = 7'b111_0011;
            default: seg = 7’b000_0000; // required, if not, bug.
        endcase
endmodule
```

```systemverilog
    input  logic [3:0] a, b,
    input  logic       sel,
```

```systemverilog
module mux2 (
    input  logic [3:0] a, b,
    input  logic       sel,
    output logic [3:0] y);
    
    assign y = (sel) ? b: a;

```
* Simple forms 2: using `always_comb` statement
```systemverilog
module mux2 (
    input  logic [3:0] a, b,
    input  logic       sel,
    output logic [3:0] y);
    
    always_comb begin
        if (sel==1’b0)
            y = a;
        else
            y = b;
    end
endmodule
```

* 4:1 multiplexer
* Using `assign` statement
```systemverilog
module mux4 (
    input  logic [3:0] a, b, c, d,
    input  logic [1:0] sel,
    output logic [3:0] y);
    
    assign y = (sel[1]) ? (sel[0] ? d: c): (sel[0]) ? b: a);
endmodule
```

```systemverilog
module mux4 (
    input  logic [3:0] a, b, c, d,
```

* Implements using `case` statement
```systemverilog
module mux4 (
    input  logic [3:0] a, b, c, d,
    input  logic [1:0] sel,
    output logic [3:0] y);
    
    always_comb begin
        case (sel) // synthesis full_case parallel_case
            2’b00: y = a;
            2’b01: y = b;
            2’b10: y = c;
            default: y = d;
        endcase
    end
endmodule
```
Case statement is same above.
Which one is better?
Cost is same, but delay... 전자는 2개, 후자는 3개.

#### Decoder
```systemverilog
module decoder ( input  logic [1:0] a,
                 output logic [3:0] y );

    always_comb begin
        case (a) // synthesis full_case parallel_case
            2’b00: y = 4’b0001;
            2’b01: y = 4’b0010;
            2’b10: y = 4’b0100;
            default: y = 4’b1000;
        endcase
    end
endmodule
```
