___

**THEOREM**)
If $R$ is a [[Ring|ring]] with unity and [[Characteristic|characteristic]] $n > 1$, then $R$ contains a subring isomorphic to $\mathbb{Z}_n$.
If $R$ has [[Characteristic|characteristic]] $0$, then $R$ contains a subring isomorphic to $\mathbb{Z}$.

___

**PROOF**)
Consider $\phi:\mathbb{Z} \rightarrow R$ in [[Thm 27.17]]. By [[Thm 19.15]], if $char(R) = n$, then $Ker(\phi) = n\mathbb{Z}$. By [[Thm 26.17]], $\mathbb{Z}/n\mathbb{Z} \cong \mathbb{Z}_n \cong \phi[\mathbb{Z}] \leq R$. If $char(R) = 0$, then $Ker(\phi) = \{0\}$, so, by, [[Thm 26.17]], $\mathbb{Z} / \{0\} \cong \mathbb{Z} \cong \phi[\mathbb{Z}] \leq R$.
